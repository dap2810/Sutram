सूत्रम्-पुस्तकम्

प्रस्तावना. Sutram इति एका सङ्गणकभाषा अस्ति यस्याः मुख्यशब्दाः संस्कृताः सन्ति - न केवलं सौन्दर्यार्थम्, अपि तु तस्याः रचनासिद्धान्तत्वेन। अस्याः नाम 'Sutram' इत्यस्य अर्थः 'सूत्रम्' इति: पणिनेः Ashtadhyayi (विश्वस्य प्रथमा औपचारिकी व्याकरणपरम्परा) इत्यस्य सङ्क्षिप्तः सूत्ररूपः नियमः। अस्याः मानकपुस्तकालयः साक्षात् भारतीयगणितीयपरम्परां प्रयुङ्क्ते - पिंगलस्य बाइनरी-पद्धतिः तथा मेरु-प्रस्तरः, आर्यभटस्य कुट्टकः, भास्कराचार्यस्य चक्रवालः च। तथा च सङ्कलनयन्त्रम् स्वयंपूर्णम् अस्ति: एकं हस्तलिखितम् असेम्बली-सञ्चिका यत् साक्षात् यन्त्रसङ्केतं जनयति, यत्र भवतः कृते कस्यापि रनटाइम अथवा टूलचेन इत्यस्य आवश्यकता नास्ति। इदं पुस्तकं भाषां आरम्भात् एव शिक्षयति। प्रत्येकम् उदाहरणं वास्तविकः सङ्केतः अस्ति यः सङ्कलितः भूत्वा चलति, तथा च भाषायाः विषये यत्किमपि कथनम् अस्ति तत् भवान् प्रमाणीकर्तुं शक्नोति।
💡 प्रयोगविधिः: कुङ्कुमचिह्नयुक्ते शब्दे माउस् नयतु — तस्य अर्थः (English) तत्क्षणम् दृश्यते.

संस्कृत-कूटशब्दः्स्। नेटिव्-मशीन्-कोड्। सर्वाः भाषाः बध्नाति एकं सूत्रम्।

1. सूत्रम् किम्? (What is Sutram?)

सूत्रम् इत्यस्य अर्थः "सूत्रम्" — यत् सर्वं बध्नाति। सूत्रम् एका कम्प्यूटर-भाषा अस्ति यस्याः कूटशब्दः्स् संस्कृतात् आगतानि, यस्याः संकलकःः शुद्धायां असेंबली-भाषायां लिखितः, या च सरलतया x86-64 मशीन-कोड्-रूपेण परिवर्तते। नास्ति इण्टरप्रेटर्, नास्ति वर्चुअल्-मशीन, नास्ति रनटाइम्-लाइब्रेरी।

कुतः शिक्षणीयम्?

१. पायथन-सदृशी सरलता, C-सदृशी वेगः। भवान् स्वच्छैः संस्कृत-कूटशब्दः्स्-भिः पठनीयं कोडं लिखति; संकलकःः लघुं नेटिव्-बाइनरी निर्माति यत् हस्त-लिखित-असेंबली-समानं वेगेन चलति।

२. सर्वं पश्यति। संकलकःः एका पठनीया असेंबली-फ़ाइल् (~९००० पङ्क्तयः) — भवान् द्रष्टुं शक्नोति यथा वास्तविकः संकलकःः कार्यं करोति: लेक्सर् → पार्सर् → कोड्-जनरेटर् → ELF-लेखकः।

३. भवतः भाषा, भवतः शब्दाः। भाषा-संकुलम्-सहाय्येन भवान् प्रत्येकं कूटशब्दः् हिन्दी-तेलुगु-बाङ्ला-तमिऴ्- आदौ लिखितुं शक्नोति। संस्कृत-कूटशब्दः्स् मूलम् — सूत्रं यत् सर्वाः भाषाः बध्नाति।

आवश्यकम्: Linux x86-64 तन्त्रम् (अथवा Windows-उपरि WSL)। अन्यः आश्रयः न।

2. भवतः प्रथमः क्रमादेशः (Your first program)

प्रत्येकं सूत्रम्-क्रमादेशः mukhya()-तः आरभते — चलनस्य "मुख्या" धारा। सेमीकोलन् ऐच्छिकम्; एकस्य कथनस्य कृते ब्रेस् अपि ऐच्छिकम्; टिप्पणी //-तः आरभते।

mukhya()
    likha("Namaste, Sutram!\n")

एतत् namaste.sm इति नाम्ना रक्षतु, ततः संकलय च प्रचालय:

$ sutram namaste.sm namaste.bin
OK: compiled 90 bytes
$ ./namaste.bin
Namaste, Sutram!
संकलकःः सम्पूर्णं चालनीयं ELF-बाइनरी निर्माति — अस्मै क्रमादेशःाय केवलं ९० बाइट्।

3. चराणि च स्थिराङ्काः (Variables and constants)

vitti ("वृत्तिः / अवस्था") इत्यनेन चरं निर्माति। पूर्णाङ्कस्य कृते anka। स्थिराङ्कस्य कृते sutra:

mukhya()
    vitti x = 10
    x = x + 5
    likha(x)        // 15
    sutra pi = 314
    likha(pi / 100)  // 3
    likha("\n")

प्रथमानि पञ्च चराणि रजिस्टरेषु (rbx, r12–r15) तिष्ठन्ति — संकलकःः स्वयम् एव नियोजयति।

4. संक्रियाः पूर्वता च (Operators and precedence)

सूत्रम्-भाषायां सम्पूर्णा संक्रिया-सूची अस्ति, गणितस्य मानक-नियमैः सह:

OperatorMeaningExample
+ - * / %arithmetic, modulo17 % 5 → 2
== != < > <= >=comparisonx >= 18
&& ||logical and / ora > 0 && b > 5
& | ^bitwise2 & 12 → 0
( ... )grouping(3 + 4) * 2 → 14

कोष्ठकानि पूर्वतां परिवर्तयन्ति — गणितस्य इव:

mukhya()
    vitti a = 3
    vitti b = 4
    likha((a + b) * 2)   // 14
    likha("\n")
    likha(17 % 5)         // 2
    likha("\n")
    likha(2 & 12)         // 0  (bitwise AND)
    likha("\n")
पूर्वता (न्यूनात् अधिकं): || → && → तुलना → + - & | ^ → * / %। सन्देहे कोष्ठकानि लिखतु — वेगः न ह्रियते।

5. निर्णयः: yadi / anyatra (Decisions (if / else))

yadi शर्तः सत्ये सति ब्लॉकं चालयति; anyatra अन्यथा।

mukhya()
    vitti mulya = 0
    yadi (mulya > 0) {
        likha("Positive\n")
    } yadi (mulya < 0) {
        likha("Negative\n")
    } anyatra {
        likha("Zero\n")
    }

एकस्य मूल्यस्य बहु-स्थिति-तुलनायै guna + bhavana उपयुज्यताम्:

mukhya()
    vitti divasa = 3
    guna (divasa) {
        bhavana 1: { likha("Somvaar\n") }
        bhavana 2: { likha("Mangalvaar\n") }
        bhavana 3: { likha("Budhvaar\n") }
        anyatra: { likha("Anyo divaah\n") }
    }

6. पाशाः: punaravartana, yavat, krama, uddeshya (Loops)

punaravartana (पुनरावृत्तिः) गणना-पाशः — "i = a तः b पर्यन्तम्":

mukhya()
    punaravartana i = 1 to 5 {
        likha(i)
        likha(" ")   // 1 2 3 4 5
    }
    likha("\n")

yavat (यावत्) while-पाशः। krama पाशं भिनत्ति; uddeshya अग्रिमं चरणं प्रति गच्छति:

mukhya()
    vitti yogam = 0
    punaravartana i = 1 to 100 {
        yadi (i > 10) { krama }
        yadi (i % 2 == 0) { uddeshya }
        yogam = yogam + i
    }
    likha(yogam)     // 25
    likha("\n")

7. फलनानि: prakriya (Functions)

prakriya (प्रक्रिया) नामकं ब्लॉकं यत् षट् यावत् तर्कान् गृह्णाति, pratiyati-द्वारा मूल्यं प्रत्यागच्छति:

prakriya vishalya(mulya)
    pratiyati mulya * mulya

mukhya()
    vitti phalam = vishalya(7)
    likha(phalam)     // 49
    likha("\n")

फलनानि स्वयम् एव आह्वयितुं शक्नुवन्ति — पुनरावृत्तिः प्रत्यक्षतः कार्यं करोति:

prakriya fib(n) {
    yadi (n < 2) { pratiyati n }
    pratiyati fib(n - 1) + fib(n - 2)
}

mukhya()
    likha(fib(10))     // 55
    likha("\n")

8. पङ्क्तयः: pankti (Arrays)

पङ्क्तिः अर्थः "श्रेणिः" — वस्तूनां एका रेखा। pankti इत्यनेन पङ्क्तिः निर्माति: pankti tarika[5] पञ्च 64-बिट्-स्थानानि ददाति:

mukhya()
    pankti tarika[5]
    punaravartana i = 0 to 5 {
        tarika[i] = i * i
    }
    likha(tarika[4])     // 16
    likha("\n")

arr[i] सरलतया पॉइन्टर्-द्वारा पठति-लिखति — एकः मशीन्-निर्देशः, C-वेगः।

9. गणनानि स्थिराङ्काः च — srijana, sutra (Enums and constants)

srijana (सृजनम्) नामकानि पूर्णाङ्क-स्थिराङ्कानि निर्माति — एकं enum:

mukhya()
    srijana LAAL = 1
    srijana HARA = 2
    srijana NEELA = 3
    vitti mera_ranga = HARA
    guna (mera_ranga) {
        bhavana 1: { likha("Red\n") }
        bhavana 2: { likha("Green\n") }
        bhavana 3: { likha("Blue\n") }
    }

14. नूतनाः विशेषताः: v22 (New features)

टिप्पनी (Comments)

क्रमादेशे टिप्पनीलेखनस्य द्वे रूपे स्तः — # तथा //। संकलकः एताः सम्पूर्णतया उपेक्षते।

# एषा हैश-टिप्पनी
vitti x = 10  # कोडस्य अनन्तरम् अपि
// एषा स्लैश-टिप्पनी
likha(x)

संयुक्तनिर्देशनम् (Compound Assignment)

vitti x = 100
x += 50   # 150
x -= 30   # 120
x *= 2    # 240
x /= 4    # 60
x %= 7    # 4

वृद्धिः ह्रासः च (++ / --)

vitti n = 5
n++      # n = 6
n--      # n = 5

सूत्रसंयोगः (String Concatenation)

संकलनकाले एव सूत्राणि संख्याः च संयुज्यन्ते:

likha("नमः " + "संसाराय\n")
likha("उत्तरम्: " + 42 + "\n")
likha(7 + " दिनानि\n")

lkhb() — नवीनपङ्क्तिं विना मुद्रणम्

likha() संख्यायाः अनन्तरं नवीनपङ्क्तिं ददाति; lkhb() न ददाति — सारणीनिर्माणाय:

punaravartana i = 1 to 5 {
    lkhb(i)
    likha(" ")
}

अवरोही पुनरावृत्तिः (Descending Loops)

प्रारम्भिकमूल्यम् अन्तिमात् मूल्यात् बृहत्तरं भवति चेत्, गणना स्वतः अवरोहति:

punaravartana i = 5 to 1 {
    lkhb(i)
    likha(" ")
}    # फलम्: 5 4 3 2 1

nishkriya() — इनलाइन यन्त्रकोडः

कच्चे x86-64 बैट्स् सर्वथा सोद्यत्नं उत्पन्ने कोडे स्थाप्यन्ते:

nishkriya("B8 3C 00 00 00")  # mov eax, 60
nishkriya("BF 2A 00 00 00")  # mov edi, 42
nishkriya("0F 05")            # syscall → exit(42)

grahan() तथा निवेशस्य अन्तः

निवेशः समाप्तः चेत् grahan() इदानीं -1 प्रयच्छति, येन क्रमादेशः शुद्धतया निवृत्तः भवितुम् अर्हति:

vitti a = grahan()
yadi (a == -1) {
    likha("निवेशः समाप्तः\n")
    krama
}

15. पारिभाषिकशब्दकोशः (Technical Glossary) (Technical glossary)

अस्मिन् पुस्तके प्रयुक्तानां पारिभाषिकशब्दानां संस्कृतरूपाणि — तेषां च युक्तिः:

Program → क्रमादेशः — क्रमेण दत्ताः आदेशाः (क्रमबद्धाः आज्ञाः)। अनेन शब्देन सङ्गणकं किं कर्तव्यम् इति निर्दिश्यते।

Compiler → संकलकः — संकलनं करोति, अतः संकलकः। स्रोतकोडं यन्त्रकोडे परिवर्तयति अनुवादकः।

Computer → संगणकम् — सम् + गणकः = गणनां करोति यत् यन्त्रम्। आधुनिकसंस्कृते प्रामाणिकः शब्दः।

Keyword → कूटशब्दः — कूटः इत्यर्थः संकेतः। भाषायै विशिष्टतया आरक्षितः शब्दः, यथा mukhya, vitti।

Variable → चरम् — चरति (भ्रमति, बदलते) इति चरम्; यस्य मूल्यं परिवर्तनीयम्। गणितशास्त्रस्य परम्परातः प्रसिद्धः शब्दः।

Constant → अचलम् — न चरति, अचलति इति; यस्य मूल्यं न परिवर्तते। "स्थिराङ्कः" इत्यपि शब्दः प्रचलितः।

Function → फलकम् — फलं ददाति इति फलकम्; प्रवेशात् (input) निर्गमस्य (output) नियमः। गणिते च सङ्गणकविज्ञाने च प्रामाणिकः।

Loop → पुनरावृत्तिः — पुनः पुनः आवर्तते (पुनः चलति) इति; बन्धसदृशा संरचना।

Array → पङ्क्तिः — पङ्क्तिबद्धानां मूल्यानां समूहः। सूत्रम्-भाषायामेव अस्य कूटशब्दः pankti अस्ति।

Memory → स्मृतिः — यत्र सूचनाः संगृह्यन्ते; "मेमोरी" इति केवलं श्रुतिलिपिः, अर्थं न ब्रूते।

Machine Code → यन्त्रकोडः — CPU इत्यनेन प्रत्यक्षतया निष्पाद्यमानः द्विअङ्कीयः कोडः। सूत्रम् प्रत्यक्षम् अत्र एव संकल्यते।

String → सूत्रम् — अक्षराणां माला। संस्कृते "सूत्रम्" इत्यस्य शाब्दिकोऽर्थः एव दारः (धागा) — अत एव भाषायाः नाम सूत्रम्!

Error → दोषः — क्रमादेशे भवति हीनता; संकलकः पङ्क्तिसंख्यया सह दोषं सूचयति।

Debugging → दोषसुधारणम् — दोषं अन्विष्य संसाधनं प्रक्रिया।

Language → भाषा — क्रमादेशभाषा: यया मनुष्यः सङ्गणकाय आदेशं ददाति।

17. विण्डोज़-स्थापनम् — पूर्णा मार्गदर्शिका

सूत्रम् विण्डोज़ं लिनक्सवत् प्रथमश्रेणीयलक्ष्यं मन्यते। पूर्वाध्यायाः सर्वे तथैव कार्यन्ते; केवलं स्थापन-चरणं भिद्यते, तदेव अस्मिन् अध्याये पूर्णतया वर्ण्यते।

17.1 किं लभ्यते

  • sutram.exe — संकलकः मूलः Win64-क्रमादेशः (PE32+)।
  • संकलिताः क्रमादेशाः वास्तविकाः विण्डोज़-कार्यक्रमाः, न स्क्रिप्टाः।
  • WSL, लिनक्स-VM, पाइथन्, C-रनटाइम् वा न आवश्यकम्।
  • एकस्मादेव संकलक-स्रोतात् उभौ संकलकौ भवतः, अतः भाषायाः व्यवहारः समानः।

17.2 आवश्यकताः

  • विण्डोज़ 10 वा 11, 64-बिट्।
  • सामान्यप्रयोगाय अन्यत् किमपि न। NASM केवलं स्वयं संकलकं निर्मातुम् आवश्यकम्।

17.3 स्थापनम् — मार्गः क: मार्गदर्शकः (अनुशंसितः)

  1. Sutram-Setup.exe प्राप्नुयात्।
  2. तस्मिन् द्विगुण-क्लिक् करोतु। नवीनक्रमादेशाय विण्डोज़ SmartScreen-चेतावनी दृश्येत: More info → Run anyway चिनोतु।
  3. मार्गदर्शकः गन्तव्यसञ्चिकां पृच्छति। पूर्वनिर्धारितम् C:\Program Files\Sutram। तत् स्वीकरोतु, अन्यथा Browse इत्यनेन स्वकीयां चिनोतु।
  4. कुत्रापि सञ्चिकायाः sutram लेखितुं शक्यते चेत् “Add Sutram to PATH” चिनोतु। एतत् अनुशंसितम्।
  5. इच्छया Start Menu-प्रवेशं, Desktop-लघुपथं च चिनोतु।
  6. Install नुदतु। समाप्तौ पिधातु।

ततः सूत्रम् Apps & Features मध्ये पञ्जीक्रियते, अतः Settings-तः संस्करणं, नवीकरणं वा अनुस्थापनं कर्तुं शक्यते।

17.4 स्थापनम् — मार्गः ख: चलनशीलसञ्चिका

  1. sutram-windows-native.zip कुत्रापि उद्घाटयतु, यथा C:\Sutram।
  2. सञ्चिका सह रक्षतु — भाषा-सञ्चयाः sutram.exe-पार्श्वे lang\ मध्ये सन्ति।
  3. तस्यामेव सञ्चिकायां टर्मिनल् उद्घाटयतु (Shift + दक्षिण-क्लिक् → Open in Terminal)।
  4. इच्छया एकवारं install.bat चालयतु — तत् सञ्चिकां PATH मध्ये योजयति।

17.5 स्थापनम् — मार्गः ग: स्रोततः निर्माणम्

विकासकर्तृभ्यः। NASM तथा PE-समर्थः संयोजकः (GNU ld, MSVC, lld-link) आवश्यकौ:

nasm -f win64 -dWINDOWS -I. src\sutram_compiler.asm -o sutram.obj
ld -mi386pep --entry=_start -o sutram.exe sutram.obj

मार्गदर्शक-स्थापकम् अपि निर्मातुं MinGW GCC तथा PowerShell आवश्यकौ; स्क्रिप्टाः windows\ मध्ये सन्ति (BUILD-WINDOWS-SETUP.cmd)।

17.6 PATH-ज्ञानम्

PATH तेषां सञ्चिकानां सूची याः विण्डोज़् आदेशं लिखति चेत् अन्विष्यति। सूत्रमः सञ्चिका PATH मध्ये चेत् कुत्रापि sutram लेखितुं शक्यते; अन्यथा पूर्णं पथं लेखितव्यं वा तस्यामेव सञ्चिकायां स्थातव्यम्।

परीक्षा: नवीनं टर्मिनल् उद्घाट्य sutram --version चालयतु। संस्करणं दृश्यते चेत् PATH सम्यक्। अन्यथा PATH-विकल्पेन स्थापकं पुनः चालयतु, अन्यथा sutram.exe यत्र अस्ति तस्याः सञ्चिकायाः चालयतु।

17.7 प्रथमः विण्डोज़-क्रमादेशः

फलस्य नाम लक्ष्यं निर्णयति: .exe विण्डोज़-कार्यक्रमं, .bin लिनक्सम्। एकः संकलकः, द्वौ लक्ष्यौ।

17.8 निर्मिते .exe किं भवति

संकलितः क्रमादेशः एकः PE32+ खण्डः:

[PE-शीर्षकाः][लघु रनटाइम्][भवतः संकलितः कोडः]

रनटाइम् आरम्भे प्रक्रिया-पर्यावरण-खण्डे चलित्वा तस्य निर्यात-सारणीं पठित्वा kernel32 अन्विष्यति, अतः क्रमादेशे न आयात-सारणी न बाह्याश्रयः भवति। सः फलम्, आगमनम्, निर्गमनं च WriteFile, ReadFile, ExitProcess प्रति नयति। सूत्रम्णा निर्मितं .exe चालयितुं किमपि स्थापयितुं न आवश्यकम्।

17.9 विण्डोज़े भाषा-सञ्चयाः

सूत्रम् द्वयोः स्थानयोः अन्विष्यति: वर्तमानसञ्चिकायाः सापेक्षं lang\<name>.lang, ततः %USERPROFILE%\.local\share\sutram\lang\। द्वितीये स्थाने स्थापिताः सञ्चयाः कुतोऽपि कार्यन्ति।

sutram.exe --lang gujarati prog.sm out.exe

दश सञ्चयाः: बङ्गाली, गुजराती, हिन्दी, कन्नडः, मलयालम्, मराठी, ओडिया, पञ्जाबी, तमिळ्, तेलुगु। कूटशब्दानां देवनागरी-वर्तनी अपि स्वीक्रियते।

17.15 विण्डोज़े अद्यापि शेषम्

अधुना कार्यन्ति: संकलनम्, likha तथा shabda, गणितम्, चराः, yadi/anyatra, yavat, punaravartana, krama/uddeshya, त्रिपर्यन्ताः फलनाः, पुनरावृत्तिः, शीघ्रं प्रत्यागमनम्, खण्ड-टिप्पण्यः, भाषा-सञ्चयाः, दोष-सन्देशाः।

विण्डोज्-आगमनम् (grahan) इदानीं कार्यं करोति: निर्मितः .exe लिनक्स-सिस्टम्-कॉल इत्यस्य स्थाने एम्बेडेड्-रन्टाइम् (ReadFile) माध्यमेन पठति। पङ्क्तिः (pankti) रचना (rachana) च VirtualAlloc माध्यमेन स्मृतिं गृह्णीतः। अद्यापि पोर्ट् न कृतम्: नेटवर्क बिल्टिन्स्। अन्तर्क्रियात्मकं REPL कार्यान्वितम् अस्ति तथा च वास्तविक-विण्डोज्-यन्त्रे परीक्षणस्य प्रतीक्षां करोति।

17.16 दर्शनम् — अपरिवर्तितम्

संकलकः एक एव शुद्ध-NASM-स्रोतः तिष्ठति, यत्र C, पाइथन् वा रनटाइम्-आश्रयः नास्ति; संस्कृतम् एव भाषायाः केन्द्रम्, प्रत्येकस्य भारतीयभाषायाः स्वकीयाः शब्दाः सन्ति; निर्मिताः क्रमादेशाः मूलाः यन्त्र-कोडाः, न कदापि व्याख्यायन्ते; अन्तिमोपयोक्त्रे कस्यापि उपकरणसमूहस्य आवश्यकता नास्ति। स्थापकः केवलं प्याकेजिङ्ग् — सः भाषायाः अंशः नास्ति।

18. नूतनं किम् — वर्तमानभाषा

अयं अध्यायः पुस्तकस्य अन्यभागानां पश्चात् योजितः। अत्र सर्वम् अद्यतनभाषायाः भागः अस्ति तथा च ज्ञातोत्तराणां विरुद्धं प्रमाणीकृतम् अस्ति, न केवलम् एकवारं सङ्कलितम्। यदि पूर्वस्मिन् अध्याये अत्र किमपि न उल्लिखितम्, तर्हि अयं अध्यायः अधिकः नवीनः अस्ति।

Floating-point सङ्ख्याः — दशम्

एका चरराशीः 64-bit IEEE-754 floating-point सङ्ख्यां धारयितुं शक्नोति। दशम् इत्यनेन तत् घोषयतु; दशमलवबिन्दुयुक्तं अक्षरं स्वयमेव float भवति।

Floats सङ्ख्याभिः सह मिलन्ति (सङ्ख्या उन्नता भवति), सर्वेषां चतुर्णां गणितीयसञ्चालकानां सर्वेषां षण्णां तुलनानां च समर्थनं कुर्वन्ति, तथा च षड्भिः दशमलवस्थानैः मुद्रयन्ति। फलनानि float प्रतिदातुं शक्नुवन्ति — सङ्कलकः तेषां प्रतिदानात् तत् अनुमाति।

वर्धनीयाः व्यूहाः — कोशः

एकः सामान्यः व्यूहः आकारे निश्चितः भवति। कोशः वर्धते: सः लघुक्षमतया आरभ्यते तथा च आवश्यकतानुसारं द्विगुणः भवति।

क्षमता दैर्घ्यं न भवति। 4 क्षमत्या घोषितस्य कोशस्य क्षमता 4 अस्ति परन्तु दैर्घ्यं 0 अस्ति, अतः किमपि न प्रविश्यते तावत् 0 सूचकाङ्कः सीमायाः बहिः भवति। एतेन जनाः एकवारं भ्रमिताः भवन्ति; एतत् जानन् एव कृतम् अस्ति, तथा च एतेन एव सूचकाङ्कनम् सुरक्षितं भवति।

प्रकारिताः व्यूहाः — कोशः दशम्

Floats धारयितुं कोशः घोषितुं शक्यते। तस्मिन् प्रविष्टाः पूर्णाङ्कमूल्याः उन्नताः भवन्ति, तथा च तस्य तत्त्वानि सर्वत्र floats इव व्यवहरन्ति।

प्रकारिताः फलनमापदण्डाः

एकं फलनं विशिष्टप्रकारस्य तर्कम् अपेक्षते, तथा च सङ्कलकः तत् परीक्षते।

एकः प्रकारितः float व्यूहः सूचकाङ्करूपेण प्रदीयते, अतः सूचकाङ्कितलेखनानि आह्वानकर्तुः कृते दृश्यन्ते — एकं फलनं भवतः कृते व्यूहं पूरयितुं शक्नोति। परन्तु तस्य वर्धनम् अनुमतं नास्ति: मापदण्डे kosh_push आह्वानं नामयुक्तदोषेण अस्वीकृतं भवति, यतः सूचकः मूल्येन प्रदीयते तथा च आह्वानकर्तुः पार्श्वे पुरातनः एव अवशिष्येत। एषा एका जानन् एव कृता सुरक्षासीमा अस्ति, न तु लुप्तं वैशिष्ट्यम्।

मानकपुस्तकालयः

सङ्कलकेन सह पञ्चदश-माड्युल-सङ्कुलानि आगच्छन्ति। आयोजनेन एकं आयातयतु। तेषु गणितं सङ्ख्यासिद्धान्तः च; वर्गीकरणं पाठ्यं च; पिंगलस्य छन्दःशास्त्रम्; आर्यभटस्य भास्कराचार्यस्य च गणितम्; पाय, साइन, कोसाइन, वर्गमूलस्य च कृते केरलसम्प्रदायस्य शृङ्खला; सांख्यिकी; सङ्ख्यात्मकं कलनम् — समाकलनं, अवकलजाः बहुपदमूलानि च; आव्यूहैः निर्धारकैः च सह रैखिकबीजगणितम्; तथा च सञ्चिकापठनं लेखनं च अन्तर्भवन्ति।

प्रयत्नं कुर्वन्तु: परम्परागतमाड्युल-सङ्कुलानि वास्तविकं गणितं गणयन्ति — 61 इत्यस्य चक्रवालः x वर्गं - 61 y वर्गं = 1 इत्यस्य लघुतमं समाधानं प्रतिददाति, यत् x = 1766319049, y = 226153980 अस्ति। तत् सप्तमशताब्द्याः पद्धतिः अस्ति, यत् सम्यक् उत्तरस्य विरुद्धं प्रमाणीकृतम् अस्ति।

सूत्रम् IDE

भाषया सह स्थापितम्। एकः एव स्वदेशी कार्यक्रमः — न पायथन्, न व्याख्याता — रेखासङ्ख्याभिः वाक्यरचना-प्रकाशनैः च युक्तः सङ्केतसम्पादकः; भवता लिखितं सङ्कलितुं चालयितुं च Ctrl-R, परिणामः अधः दर्शितः; एकैकशः उदाहरणकार्यक्रमान् द्रष्टुं Ctrl-E; एकः अन्तर्क्रियाशीलः कमाण्ड-प्रवेशः यत्र भवान् कथनं टङ्कयति, Enter नुदति, तत् च चाल्यमानं पश्यति, यत्र सत्रं पूर्वतनीः पङ्क्तीः स्मरति येन भवान् एकैकं पदं कृत्वा किमपि निर्मातुं शक्नोति; तथा च रक्षितुं Ctrl-S, भारयितुं Ctrl-L, त्यक्तुं च Ctrl-Q।

विण्डोज् मध्ये IDE अद्यापि उपलब्धं नास्ति; तस्य स्थाने अन्तर्क्रियाशील-प्रवेशस्य उपयोगं कुर्वन्तु।

गतिः, न तु केवलं प्रतिपादितम्

सङ्कलकः चरराशीनां मूल्यानि स्मृतेः स्थाने प्रोसेसर-पञ्जिकासु स्थापयति। एकस्मिन् प्रतिनिधि-सङ्ख्यात्मक-कार्यक्रमे एतेन नूतनेषु चक्रेषु प्रायः 1.2 गुणितं मापितं वेगवर्धनं उत्पादितम्, तथा च एकस्मिन् दृढे पूर्णाङ्क-लूप् मध्ये उत्पादितः सङ्केतः 13 निर्देशाभ्यः 5 अभवत् — मापितं 4.9 गुणितम्। अस्मिन् खण्डे प्रत्येकं दावः तस्यामेव यन्त्रे पूर्वं पश्चात् च मापितः आसीत्, न तु अनुमानितः।

प्रकल्पः किमर्थं सावधानः अस्ति

चत्वारः स्मृति-भ्रंश-दोषाः प्राप्ताः निवारिताः च, प्रत्येकम् इदानीं स्थायि-परीक्षणेन आच्छादितम् अस्ति। सङ्कलकः 160 परीक्षणैः तथा च द्वादश-सङ्केत-आकार-द्वारैः परीक्षितः भवति ये दावं कुर्वन्ति यत् दत्तं निर्माणं कियत् सङ्केतं उत्पादितुं अनुमतम् अस्ति। यत्र प्रकल्पः किमपि प्रमाणीकर्तुं न शक्नोति — विण्डोज् अद्यापि वास्तविके विण्डोज्-यन्त्रे न चालितम् — तत् अन्यथा सूचयितुं स्थाने स्पष्टतया कथयति।

19. Code appendix for chapter 18

The examples are given here in Sutram source, which is the same in every edition of this book.

Floats

dasham x = 1.5
dasham y = 2.25
likha(x + y)      # 3.750000

Growable arrays

kosh xs[4]
kosh_push(xs, 10)
kosh_push(xs, 20)
likha(kosh_len(xs))    # 2
likha(xs[0])            # 10
dasham last = kosh_pop(xs)

Typed arrays

kosh dasham temps[4]
kosh_push(temps, 36.6)
kosh_push(temps, 37)      # promoted to 37.0
likha(temps[1])            # 37.000000

A typed function parameter

prakriya mean(kosh dasham xs) {
    dasham s = 0.0
    vitti i = 0
    yavat (i < kosh_len(xs)) {
        s = s + xs[i]
        i = i + 1
    }
    pratiyati s / kosh_len(xs)
}
