प्रस्तावना. Sutram इति एका सङ्गणकभाषा अस्ति यस्याः मुख्यशब्दाः संस्कृताः सन्ति - न केवलं सौन्दर्यार्थम्, अपि तु तस्याः रचनासिद्धान्तत्वेन। अस्याः नाम 'Sutram' इत्यस्य अर्थः 'सूत्रम्' इति: पणिनेः Ashtadhyayi (विश्वस्य प्रथमा औपचारिकी व्याकरणपरम्परा) इत्यस्य सङ्क्षिप्तः सूत्ररूपः नियमः। अस्याः मानकपुस्तकालयः साक्षात् भारतीयगणितीयपरम्परां प्रयुङ्क्ते - पिंगलस्य बाइनरी-पद्धतिः तथा मेरु-प्रस्तरः, आर्यभटस्य कुट्टकः, भास्कराचार्यस्य चक्रवालः च। तथा च सङ्कलनयन्त्रम् स्वयंपूर्णम् अस्ति: एकं हस्तलिखितम् असेम्बली-सञ्चिका यत् साक्षात् यन्त्रसङ्केतं जनयति, यत्र भवतः कृते कस्यापि रनटाइम अथवा टूलचेन इत्यस्य आवश्यकता नास्ति। इदं पुस्तकं भाषां आरम्भात् एव शिक्षयति। प्रत्येकम् उदाहरणं वास्तविकः सङ्केतः अस्ति यः सङ्कलितः भूत्वा चलति, तथा च भाषायाः विषये यत्किमपि कथनम् अस्ति तत् भवान् प्रमाणीकर्तुं शक्नोति।

1. सूत्रम् किम्? (What is Sutram?)

सूत्रम् इत्यस्य अर्थः "सूत्रम्" — यत् सर्वं बध्नाति। सूत्रम् एका कम्प्यूटर-भाषा अस्ति यस्याः कूटशब्दः्स् संस्कृतात् आगतानि, यस्याः संकलकःः शुद्धायां असेंबली-भाषायां लिखितः, या च सरलतया x86-64 मशीन-कोड्-रूपेण परिवर्तते। नास्ति इण्टरप्रेटर्, नास्ति वर्चुअल्-मशीन, नास्ति रनटाइम्-लाइब्रेरी।

कुतः शिक्षणीयम्?

१. पायथन-सदृशी सरलता, C-सदृशी वेगः। भवान् स्वच्छैः संस्कृत-कूटशब्दः्स्-भिः पठनीयं कोडं लिखति; संकलकःः लघुं नेटिव्-बाइनरी निर्माति यत् हस्त-लिखित-असेंबली-समानं वेगेन चलति।

२. सर्वं पश्यति। संकलकःः एका पठनीया असेंबली-फ़ाइल् (~९००० पङ्क्तयः) — भवान् द्रष्टुं शक्नोति यथा वास्तविकः संकलकःः कार्यं करोति: लेक्सर् → पार्सर् → कोड्-जनरेटर् → ELF-लेखकः।

३. भवतः भाषा, भवतः शब्दाः। भाषा-संकुलम्-सहाय्येन भवान् प्रत्येकं कूटशब्दः् हिन्दी-तेलुगु-बाङ्ला-तमिऴ्- आदौ लिखितुं शक्नोति। संस्कृत-कूटशब्दः्स् मूलम् — सूत्रं यत् सर्वाः भाषाः बध्नाति।

आवश्यकम्: Linux x86-64 तन्त्रम् (अथवा Windows-उपरि WSL)। अन्यः आश्रयः न।

2. भवतः प्रथमः क्रमादेशः (Your first program)

प्रत्येकं सूत्रम्-क्रमादेशः mukhya()-तः आरभते — चलनस्य "मुख्या" धारा। सेमीकोलन् ऐच्छिकम्; एकस्य कथनस्य कृते ब्रेस् अपि ऐच्छिकम्; टिप्पणी //-तः आरभते।

mukhya()
    likha("Namaste, Sutram!\n")

एतत् namaste.sm इति नाम्ना रक्षतु, ततः संकलय च प्रचालय:

$ sutram namaste.sm namaste.bin
Siddh: 97 baait sankalit
$ ./namaste.bin
Namaste, Sutram!
संकलकःः सम्पूर्णं चालनीयं ELF-बाइनरी निर्माति — अस्मै क्रमादेशःाय केवलं ९० बाइट्।

3. चराणि च स्थिराङ्काः (Variables and constants)

vitti ("वृत्तिः / अवस्था") इत्यनेन चरं निर्माति। पूर्णाङ्कस्य कृते anka। स्थिराङ्कस्य कृते sutra:

mukhya()
    vitti x = 10
    x = x + 5
    likha(x)        // 15
    sutra pi = 314
    likha(pi / 100)  // 3
    likha("\n")

प्रथमानि पञ्च चराणि रजिस्टरेषु (rbx, r12–r15) तिष्ठन्ति — संकलकःः स्वयम् एव नियोजयति।

4. संक्रियाः पूर्वता च (Operators and precedence)

सूत्रम्-भाषायां सम्पूर्णा संक्रिया-सूची अस्ति, गणितस्य मानक-नियमैः सह:

OperatorMeaningExample
+ - * / %arithmetic, modulo17 % 5 → 2
== != < > <= >=comparisonx >= 18
&& ||logical and / ora > 0 && b > 5
& | ^bitwise2 & 12 → 0
( ... )grouping(3 + 4) * 2 → 14

कोष्ठकानि पूर्वतां परिवर्तयन्ति — गणितस्य इव:

mukhya()
    vitti a = 3
    vitti b = 4
    likha((a + b) * 2)   // 14
    likha("\n")
    likha(17 % 5)         // 2
    likha("\n")
    likha(2 & 12)         // 0  (bitwise AND)
    likha("\n")
पूर्वता (न्यूनात् अधिकं): || → && → तुलना → + - & | ^ → * / %। सन्देहे कोष्ठकानि लिखतु — वेगः न ह्रियते।

5. निर्णयः: yadi / anya (Decisions (if / else))

yadi शर्तः सत्ये सति ब्लॉकं चालयति; anya अन्यथा।

mukhya()
    vitti mulya = 0
    yadi (mulya > 0) {
        likha("Positive\n")
    } yadi (mulya < 0) {
        likha("Negative\n")
    } anya {
        likha("Zero\n")
    }

एकस्य मूल्यस्य बहु-स्थिति-तुलनायै guna + bhavana उपयुज्यताम्:

mukhya()
    vitti divasa = 3
    guna (divasa) {
        bhavana 1: { likha("Somvaar\n") }
        bhavana 2: { likha("Mangalvaar\n") }
        bhavana 3: { likha("Budhvaar\n") }
        anya: { likha("Anyo divaah\n") }
    }

6. पाशाः: chakra, yavat, krama, agrim (Loops)

chakra (पुनरावृत्तिः) गणना-पाशः — "i = a तः b पर्यन्तम्":

mukhya()
    chakra i = 1 tak 5 {
        likha(i)
        likha(" ")   // 1 2 3 4 5
    }
    likha("\n")

yavat (यावत्) while-पाशः। krama पाशं भिनत्ति; agrim अग्रिमं चरणं प्रति गच्छति:

mukhya()
    vitti yogam = 0
    chakra i = 1 tak 100 {
        yadi (i > 10) { krama }
        yadi (i % 2 == 0) { agrim }
        yogam = yogam + i
    }
    likha(yogam)     // 25
    likha("\n")

7. फलनानि: prakriya (Functions)

prakriya (प्रक्रिया) नामकं ब्लॉकं यत् षट् यावत् तर्कान् गृह्णाति, nivartanam-द्वारा मूल्यं प्रत्यागच्छति:

prakriya vishalya(mulya)
    nivartanam mulya * mulya

mukhya()
    vitti phalam = vishalya(7)
    likha(phalam)     // 49
    likha("\n")

फलनानि स्वयम् एव आह्वयितुं शक्नुवन्ति — पुनरावृत्तिः प्रत्यक्षतः कार्यं करोति:

prakriya fib(n) {
    yadi (n < 2) { nivartanam n }
    nivartanam fib(n - 1) + fib(n - 2)
}

mukhya()
    likha(fib(10))     // 55
    likha("\n")

8. पङ्क्तयः: mala (Arrays)

पङ्क्तिः अर्थः "श्रेणिः" — वस्तूनां एका रेखा। mala इत्यनेन पङ्क्तिः निर्माति: mala tarika[5] पञ्च 64-बिट्-स्थानानि ददाति:

mukhya()
    mala tarika[5]
    chakra i = 0 tak 4 {
        tarika[i] = i * i
    }
    likha(tarika[4])     // 16
    likha("\n")

tak अन्तिमम् अङ्कम् अपि गृह्णाति, अतः 0 tak 4 पञ्च स्थानानि: 0, 1, 2, 3, 4। arr[i] परिमाणेन परीक्ष्यते: tarika[5] Sutram truti: mala ank seema atikram (सूचकः अन्तम् अतिक्रामति) इति वदित्वा क्रमादेशं विरामयति, पङ्क्तेः बाह्यां स्मृतिं न स्पृशति। वर्धमानायै पङ्क्त्यै अध्यायः 19 द्रष्टव्यः।

9. गणनानि स्थिराङ्काः च — ganana, sutra (Enums and constants)

ganana (सृजनम्) नामकानि पूर्णाङ्क-स्थिराङ्कानि निर्माति — एकं enum:

mukhya()
    ganana LAAL = 1
    ganana HARA = 2
    ganana NEELA = 3
    vitti mera_ranga = HARA
    guna (mera_ranga) {
        bhavana 1: { likha("Red\n") }
        bhavana 2: { likha("Green\n") }
        bhavana 3: { likha("Blue\n") }
    }

14. भाषायाः अन्यत्: टिप्पण्यः, लघुमार्गाः, ग्रन्थालयः (More of the language: comments, shortcuts, the library)

टिप्पनी (Comments)

क्रमादेशे टिप्पनीलेखनस्य द्वे रूपे स्तः — # तथा //। संकलकः एताः सम्पूर्णतया उपेक्षते।

# एषा हैश-टिप्पनी
vitti x = 10  # कोडस्य अनन्तरम् अपि
// एषा स्लैश-टिप्पनी
likha(x)

संयुक्तनिर्देशनम् (Compound Assignment)

vitti x = 100
x += 50   # 150
x -= 30   # 120
x *= 2    # 240
x /= 4    # 60
x %= 7    # 4

वृद्धिः ह्रासः च (++ / --)

vitti n = 5
n++      # n = 6
n--      # n = 5

सूत्रसंयोगः (String Concatenation)

संकलनकाले एव सूत्राणि संख्याः च संयुज्यन्ते:

likha("नमः " + "संसाराय\n")
likha("उत्तरम्: " + 42 + "\n")
likha(7 + " दिनानि\n")

likha_santat() — नवीनपङ्क्तिं विना मुद्रणम्

likha() संख्यायाः अनन्तरं नवीनपङ्क्तिं ददाति; likha_santat() न ददाति — सारणीनिर्माणाय:

chakra i = 1 tak 5 {
    likha_santat(i)
    likha(" ")
}

अवरोही पुनरावृत्तिः (Descending Loops)

प्रारम्भिकमूल्यम् अन्तिमात् मूल्यात् बृहत्तरं भवति चेत्, गणना स्वतः अवरोहति:

chakra i = 5 tak 1 {
    likha_santat(i)

15. पारिभाषिकशब्दकोशः (Technical Glossary) (Technical glossary)

अस्मिन् पुस्तके प्रयुक्तानां पारिभाषिकशब्दानां संस्कृतरूपाणि — तेषां च युक्तिः:

Program → क्रमादेशः — क्रमेण दत्ताः आदेशाः (क्रमबद्धाः आज्ञाः)। अनेन शब्देन सङ्गणकं किं कर्तव्यम् इति निर्दिश्यते।

Compiler → संकलकः — संकलनं करोति, अतः संकलकः। स्रोतकोडं यन्त्रकोडे परिवर्तयति अनुवादकः।

Computer → संगणकम् — सम् + गणकः = गणनां करोति यत् यन्त्रम्। आधुनिकसंस्कृते प्रामाणिकः शब्दः।

Keyword → कूटशब्दः — कूटः इत्यर्थः संकेतः। भाषायै विशिष्टतया आरक्षितः शब्दः, यथा mukhya, vitti।

Variable → चरम् — चरति (भ्रमति, बदलते) इति चरम्; यस्य मूल्यं परिवर्तनीयम्। गणितशास्त्रस्य परम्परातः प्रसिद्धः शब्दः।

Constant → अचलम् — न चरति, अचलति इति; यस्य मूल्यं न परिवर्तते। "स्थिराङ्कः" इत्यपि शब्दः प्रचलितः।

Function → फलकम् — फलं ददाति इति फलकम्; प्रवेशात् (input) निर्गमस्य (output) नियमः। गणिते च सङ्गणकविज्ञाने च प्रामाणिकः।

Loop → पुनरावृत्तिः — पुनः पुनः आवर्तते (पुनः चलति) इति; बन्धसदृशा संरचना।

Array → पङ्क्तिः — पङ्क्तिबद्धानां मूल्यानां समूहः। सूत्रम्-भाषायामेव अस्य कूटशब्दः mala अस्ति।

Memory → स्मृतिः — यत्र सूचनाः संगृह्यन्ते; "मेमोरी" इति केवलं श्रुतिलिपिः, अर्थं न ब्रूते।

Machine Code → यन्त्रकोडः — CPU इत्यनेन प्रत्यक्षतया निष्पाद्यमानः द्विअङ्कीयः कोडः। सूत्रम् प्रत्यक्षम् अत्र एव संकल्यते।

String → सूत्रम् — अक्षराणां माला। संस्कृते "सूत्रम्" इत्यस्य शाब्दिकोऽर्थः एव दारः (धागा) — अत एव भाषायाः नाम सूत्रम्!

Error → दोषः — क्रमादेशे भवति हीनता; संकलकः पङ्क्तिसंख्यया सह दोषं सूचयति।

Debugging → दोषसुधारणम् — दोषं अन्विष्य संसाधनं प्रक्रिया।

Language → भाषा — क्रमादेशभाषा: यया मनुष्यः सङ्गणकाय आदेशं ददाति।

17.6 PATH-ज्ञानम्

PATH तेषां सञ्चिकानां सूची याः विण्डोज़् आदेशं लिखति चेत् अन्विष्यति। सूत्रमः सञ्चिका PATH मध्ये चेत् कुत्रापि sutram लेखितुं शक्यते; अन्यथा पूर्णं पथं लेखितव्यं वा तस्यामेव सञ्चिकायां स्थातव्यम्।

Floating-point सङ्ख्याः — दशम्

एका चरराशीः 64-bit IEEE-754 floating-point सङ्ख्यां धारयितुं शक्नोति। दशम् इत्यनेन तत् घोषयतु; दशमलवबिन्दुयुक्तं अक्षरं स्वयमेव float भवति।

Floats सङ्ख्याभिः सह मिलन्ति (सङ्ख्या उन्नता भवति), सर्वेषां चतुर्णां गणितीयसञ्चालकानां सर्वेषां षण्णां तुलनानां च समर्थनं कुर्वन्ति, तथा च षड्भिः दशमलवस्थानैः मुद्रयन्ति। फलनानि float प्रतिदातुं शक्नुवन्ति — सङ्कलकः तेषां प्रतिदानात् तत् अनुमाति।

वर्धनीयाः व्यूहाः — कोशः

एकः सामान्यः व्यूहः आकारे निश्चितः भवति। कोशः वर्धते: सः लघुक्षमतया आरभ्यते तथा च आवश्यकतानुसारं द्विगुणः भवति।

क्षमता दैर्घ्यं न भवति। 4 क्षमत्या घोषितस्य कोशस्य क्षमता 4 अस्ति परन्तु दैर्घ्यं 0 अस्ति, अतः किमपि न प्रविश्यते तावत् 0 सूचकाङ्कः सीमायाः बहिः भवति। एतेन जनाः एकवारं भ्रमिताः भवन्ति; एतत् जानन् एव कृतम् अस्ति, तथा च एतेन एव सूचकाङ्कनम् सुरक्षितं भवति।

प्रकारिताः व्यूहाः — कोशः दशम्

Floats धारयितुं कोशः घोषितुं शक्यते। तस्मिन् प्रविष्टाः पूर्णाङ्कमूल्याः उन्नताः भवन्ति, तथा च तस्य तत्त्वानि सर्वत्र floats इव व्यवहरन्ति।

प्रकारिताः फलनमापदण्डाः

एकं फलनं विशिष्टप्रकारस्य तर्कम् अपेक्षते, तथा च सङ्कलकः तत् परीक्षते।

एकः प्रकारितः float व्यूहः सूचकाङ्करूपेण प्रदीयते, अतः सूचकाङ्कितलेखनानि आह्वानकर्तुः कृते दृश्यन्ते — एकं फलनं भवतः कृते व्यूहं पूरयितुं शक्नोति। परन्तु तस्य वर्धनम् अनुमतं नास्ति: मापदण्डे kosh_kship आह्वानं नामयुक्तदोषेण अस्वीकृतं भवति, यतः सूचकः मूल्येन प्रदीयते तथा च आह्वानकर्तुः पार्श्वे पुरातनः एव अवशिष्येत। एषा एका जानन् एव कृता सुरक्षासीमा अस्ति, न तु लुप्तं वैशिष्ट्यम्।

मानकपुस्तकालयः

सङ्कलकेन सह पञ्चदश-माड्युल-सङ्कुलानि आगच्छन्ति। आयोजनेन एकं आयातयतु। तेषु गणितं सङ्ख्यासिद्धान्तः च; वर्गीकरणं पाठ्यं च; पिंगलस्य छन्दःशास्त्रम्; आर्यभटस्य भास्कराचार्यस्य च गणितम्; पाय, साइन, कोसाइन, वर्गमूलस्य च कृते केरलसम्प्रदायस्य शृङ्खला; सांख्यिकी; सङ्ख्यात्मकं कलनम् — समाकलनं, अवकलजाः बहुपदमूलानि च; आव्यूहैः निर्धारकैः च सह रैखिकबीजगणितम्; तथा च सञ्चिकापठनं लेखनं च अन्तर्भवन्ति।

प्रयत्नं कुर्वन्तु: परम्परागतमाड्युल-सङ्कुलानि वास्तविकं गणितं गणयन्ति — 61 इत्यस्य चक्रवालः x वर्गं - 61 y वर्गं = 1 इत्यस्य लघुतमं समाधानं प्रतिददाति, यत् x = 1766319049, y = 226153980 अस्ति। तत् सप्तमशताब्द्याः पद्धतिः अस्ति, यत् सम्यक् उत्तरस्य विरुद्धं प्रमाणीकृतम् अस्ति।

19. स्मृतिः: kosh, mandapa, परिमितिः, विभागाः च (Memory: kosh, mandapa, budgets and slices)

प्रत्येकः क्रमादेशः स्वान् अङ्कान् कुत्रचित् स्थापयति। अयम् अध्यायः वदति - कुत्र, कियत्, स्मृतौ न्यूनायां च सूत्रम् किं करोति इति। अद्यतनं सङ्कलकं (v315) वर्णयति।

1. mala स्थिरा पङ्क्तिः; kosh वर्धते (a mala is fixed; a kosh grows)

mala यत् परिमाणं दीयते तत् सदा धारयति। kosh यावतां अङ्कानां स्थानं दीयते तावता आरभते। यदा पूर्णः सन् kosh_kship इत्यनेन अन्यः योज्यते, तदा स्वयमेव द्विगुणं स्थानं करोति, अग्रे च गच्छति। kosh_gan कति धारयति इति वदति; कतीनां स्थानम् अस्ति - सा तस्य धारिता (capacity)।

mukhya() {
    mala dinah[3]            # ठीक त्रयः अङ्काः
    dinah[0] = 30
    dinah[1] = 28
    dinah[2] = 31
    likha(dinah[2])          # 31
    kosh ankah[2]            # आरम्भे द्वयोः स्थानम्, किमपि नास्ति
    kosh_kship(ankah, 5)
    kosh_kship(ankah, 7)
    kosh_kship(ankah, 9)        # तृतीयः: कोशः स्वयं वर्धते
    likha(kosh_gan(ankah))    # 3
    likha(ankah[2])          # 9
}

mala उपयुज्यताम् यदा सङ्ख्या पूर्वमेव ज्ञाता (सप्ताहस्य दिनानि, फलकस्य कोष्ठाः)। kosh उपयुज्यताम् यदा न ज्ञाता (पत्रे शब्दाः, जनः यान् अङ्कान् लिखति)। उभे परीक्ष्येते: dinah[3] पठनं Sutram truti: mala ank seema atikram (सूचकः अन्तम् अतिक्रामति) इति वदित्वा क्रमादेशं विरामयति, परं स्थितं किमपि न पठति।

2. mandapa: यस्य स्मृतिः प्रत्यर्प्यते सः खण्डः (a block whose memory is given back)

nirmmita(n) नवान् शून्यीकृतान् n बाइट्-परिमितान् स्मृतिभागान् ददाति। खण्डात् बहिः ते क्रमादेशस्य अन्तपर्यन्तं तिष्ठन्ति। mandapa-मध्ये तु ते क्षणिकाः: खण्डे nirmmita-निर्मितं सर्वं खण्डस्य समाप्तौ एकवारं प्रत्यर्प्यते - यथा कथञ्चित् समाप्तः भवतु (अन्तिमा पङ्क्तिः, nivartanam, krama)।

prakriya kaam(i) {
    mandapa {
        vitti b = nirmmita(256)     # 256 बाइट् क्षणिकम्
        b[0] = i
        nivartanam b[0]           # अङ्कः खण्डात् निर्गच्छति: अनुमतम्
    }
    nivartanam 0
}
mukhya() {
    vitti s = 0
    chakra i = 1 tak 200000 {
        s = s + kaam(i)
    }
    likha(s)                  # 20000100000
}

मापितम् (Linux, v315, सम्पूर्णे धावने सर्वाधिका निवासि-स्मृतिः): अयं क्रमादेशः - 200,000 आह्वानानि, प्रत्येकं 256 बाइट् - 308 अथवा 436 KB पर्यन्तं गच्छति (75 धावनेषु प्रतिवारं तयोः एकम्; एतावति परिमाणे धावनात् धावनं कतिचन पृष्ठानि भिद्यन्ते)। mandapa-पङ्क्तिं विना स एव प्रतिवारं 49,920 KB, यतः 200,000 अपि खण्डाः तिष्ठन्ति: खण्डेन सह शिखरं 99% अधिकं न्यूनम्। एकं यन्त्रम्, एकः क्रमादेशः - न सर्वेषां क्रमादेशानां प्रतिज्ञा। अङ्काः खण्डात् निर्गन्तुं शक्नुवन्ति; खण्डे निर्मितः स्थान-सङ्केतः (address) न शक्नोति: बाह्य-चरे स्थापनं प्रत्यर्पणं वा सङ्कलन-समये निषिध्यते (E_SCRATCH_ESCAPE)। खण्डः केवलं तत्र nirmmita-निर्मितं प्रत्यर्पयति - यत् मुद्रितं, पत्रे लिखितं वा, तत् न निवर्तयति।

3. parimana(): अहं कियत् धारयामि? (how much am I holding?)

parimana() क्रमादेशस्य आवण्टनानि इदानीं कति बाइट् धारयन्ति इति ददाति।

mukhya() {
    likha(parimana())              # 0: अद्यापि किमपि न
    mandapa {
        vitti t = nirmmita(1000)
        t[0] = 42
        likha(t[0])                # 42
        likha(parimana())          # 1008: 1000, 16-गुणितं यावत् वर्धितम्
    }
    likha(parimana())              # 0: खण्डः प्रत्यर्पितवान्
}

क्रमादेशः यत् याचितवान् तत् गणयति, न तु यत् प्रचालन-तन्त्रं (operating system) वदति। kosh तस्य स्थानेन गण्यते, न तु तस्मिन् यत् अस्ति तेन: आत्मनः लेखाय 32 बाइट्, प्रत्येकस्मै अङ्काय यस्य स्थानम् अस्ति 8 बाइट् - उपयुक्तं वा न वा। (यः क्रमादेशः mandapa-मध्ये kosh रचयति, तस्मिन् प्रत्येकः kosh 24 बाइट् अधिकं लेखं धारयति - सर्वं 56।) kosh स्वान् बाइट्-भागान् सम्पूर्णं क्रमादेशं धारयति - खण्डे निर्मितः अपि - अतः parimana()-मध्ये तस्य भागः न न्यूनीभवति।

4. mandapa parimita N: निषेधन्ती परिमितिः (a budget that refuses)

खण्डाय बाइट्-परिमितिं ददातु; यत् आवण्टनं तां अतिक्रामेत् तत् भवनात् पूर्वमेव निषिध्यते:

mukhya() {
    mandapa parimita 1000 {
        vitti a = nirmmita(512)
        likha(parimana())          # 512
        vitti b = nirmmita(512)     # 1024 > 1000: निषिद्धम्
        likha(99)                  # न प्राप्यते
    }
}
512
Sutram truti [E_PARIMITA]: pankti 2 - mandape parimitat adhikam nirmmitam na sambhavati (parimitih 1000 baait)

क्रमादेशः निर्गम-स्थितिः 1 इत्यनेन, पङ्क्तिं परिमितिं च नामयता वाक्येन विरमति। किमर्थम् इदं श्रेयः: यः क्रमादेशः केवलं स्मृतिं गृह्णाति, तं प्रचालन-तन्त्रं विरामयति - वाक्यं विना, प्रायः सम्पूर्णं यन्त्रं मन्दीकृत्य। परिमितिः "यन्त्रस्य स्मृतिः समाप्ता" इत्येतत् "अयं खण्डः अत्र अनुमतात् अधिकं याचितवान्" इति करोति। N क्रमादेशे लिखितः अङ्कः एव भवेत्। परिमितिः खण्डे लिखितं nirmmita गणयति - न kosh, न आहूतायाः prakriya-याः आवण्टनम्।

5. विभागः, तस्य एकः नियमः च (a slice, and its one rule)

k[1:3] विभागः (slice): k-स्य 1, 2 तत्त्वयोः दर्शनम्, प्रतिलिपिं विना। vibhag-तर्कः तं गृह्णाति:

prakriya yoga(vibhag s) {
    vitti y = 0
    chakra i = 0 tak pankti_gan(s) - 1 {
        y = y + s[i]
    }
    nivartanam y
}
mukhya() {
    kosh k[4]
    kosh_kship(k, 1)
    kosh_kship(k, 2)
    kosh_kship(k, 3)
    kosh_kship(k, 4)
    likha(yoga(k[1:3]))     # 5: 1, 2 तत्त्वे
    likha(yoga(k))          # 10: सम्पूर्णः कोशः k[:] इव दीयते
}

नियमः: kosh-स्य विभागं यत्र रचयसि तत्रैव उपयुङ्क्ष्व - पठन्त्यै prakriya-यै साक्षात् प्रेषय - न तु रक्ष। यदा kosh वर्धते तदा तस्य तत्त्वानि बृहत्तरं स्थानं गच्छन्ति; पूर्वं रक्षितः विभागः पुरातनं स्थानम् एव पश्येत्। अतः सङ्कलकः, क्रमादेशस्य धावनात् पूर्वमेव, वृद्धेः परं विभागस्य रक्षणस्य सर्वान् मार्गान् निषेधति:

mukhya() {
    kosh k[4]
    kosh_kship(k, 1)
    vitti s = k[0:1]      # निषिद्धम्: E_KOSH_VIBHAG - कोश-विभागः नाम्नि न स्थाप्यते
    kosh_kship(k, 2)
    likha(s[0])
}
prakriya badha(kosh k, vibhag s) {
    kosh_kship(k, 50)           # इयं प्रक्रिया k वर्धयितुं शक्नोति ...
    nivartanam s[0]
}
mukhya() {
    kosh k[2]
    kosh_kship(k, 7)
    likha(badha(k, k[0:1]))  # ... अतः k-विभागः तस्यै न दीयते: E_KOSH_VIBHAG
}

विभागः अङ्कः अपि न। गणिते, तुलनायां, प्रतिबन्धे वा तस्य उपयोगः अन्येन सङ्केतेन निषिध्यते, E_VIBHAG_ANKA। तत्त्वानि s[i] इत्यनेन पठ, दैर्घ्यं pankti_gan(s) इत्यनेन:

mukhya() {
    kosh k[4]
    kosh_kship(k, 1)
    vitti n = k[0:1] + 0  # निषिद्धम्: E_VIBHAG_ANKA - विभागः अङ्कवत् उपयुक्तः
    likha(n)
}

अतः: E_KOSH_VIBHAG = "अयं विभागः वृद्धेः परं जीवेत्"; E_VIBHAG_ANKA = "अयं विभागः अङ्कवत् उपयुज्यते"। उभौ सङ्कलकः एव पश्यति - kosh वस्तुतः वर्धते वा न वा इति न प्रतीक्षते।

6. यदा स्मृतिः समाप्यते (when memory runs out)

यदि kosh_kship-याः अधिकं स्थानम् आवश्यकं, यन्त्रं च दातुं न शक्नोति, तर्हि क्रमादेशः इदं वाक्यं निर्गम-स्थितिः 1 च दत्त्वा विरमति:

Sutram truti: kosh vardhayitum smritih na labdha - kosh yatha asit tatha eva

कोशं वर्धयितुं स्मृतिः न लब्धा - कोशः यथा आसीत् तथा एव। उत्तरार्धं ज्ञातव्यम्: kosh न दूषितः। विफलात् योजनात् पूर्वं यत् धारयति स्म तत् एव धारयति - क्रमादेशः अर्धलिखितं कोशं कदापि न त्यजति। क्रमादेशः तु विरमति एव: इयं विफलता न गृहीत्वा अग्रे गन्तुं शक्या।

सर्वं मिलित्वा (putting it together)

बहिः निर्मितः kosh, प्रत्यावर्तं परिमितः खण्डः, प्रतिवारं खण्डात् बहिः नीतः अङ्कः:

mukhya() {
    kosh vargah[4]
    chakra i = 1 tak 5 {
        mandapa parimita 256 {
            vitti t = nirmmita(16)
            t[0] = i * i
            kosh_kship(vargah, t[0])     # अङ्कः कोशं गच्छति
        }
    }
    likha(kosh_gan(vargah))           # 5
    likha(vargah[4])                 # 25
    likha(parimana())                # 96: केवलं कोशः - प्रत्येकः खण्डः स्वान् 16 बाइट् प्रत्यर्पितवान्
}

कोशे पञ्च अङ्काः - 40 बाइट् - तर्हि किमर्थं 96? यतः parimana() कोशस्य स्थानं गणयति, न तु तस्य अन्तर्वस्तु। आरम्भे चतुर्णां स्थानम् आसीत्। पञ्चमः अङ्कः तं पूर्णं प्राप्नोत्, अतः सः अष्टानां स्थानम् अकरोत्। 96 = कोशस्य स्व-लेखस्य 32 बाइट् + अष्टानां अङ्कानां स्थानम् (8 × 8): 32 + 64। तेषु अष्टसु त्रीणि स्थानानि रिक्तानि, आगामिनः त्रीन् अङ्कान् प्रतीक्षन्ते।

7. सूत्रे किं नास्ति (what Sutram does not have)

वस्तुनः आकारं ज्ञातुम्: अवकर-सङ्ग्राहकः (garbage collector) नास्ति (पृष्ठभूमौ स्मृतिं प्रत्याहर्तुं किमपि न धावति); भवता आह्वातव्यं free नास्ति (स्मृतिः खण्डस्य समाप्तौ, क्रमादेशस्य समाप्तौ वा प्रत्यागच्छति - प्रत्यर्पणाय भवता किमपि न आह्वातव्यम्); जीवति खण्डे पुनरुपयोगः नास्ति (खण्डः समाप्तौ एव, एकवारं, स्मृतिं प्रत्यर्पयति); तन्तवः (threads) न सन्ति (एकः क्रमादेशः एकस्मिन् काले एकम् एव करोति)। खण्डे निर्मितः kosh खण्डं त्यक्तुं न शक्नोति (E_KOSH_MANDAPA)। तत्स्थाने यत् लभ्यते तत् लघु पूर्वानुमेयं च: स्मृतिः कुत्र धार्यते इति द्रष्टुं, कियत् इति प्रष्टुं (parimana()), तां सीमितुं (parimita) शक्यते; वर्धितुम् अशक्तः kosh, परिमितिम् अतिक्रान्तः खण्डः, पूर्णं खण्ड-क्षेत्रं वा - प्रत्येकं किम् इति वदता वाक्येन क्रमादेशं विरामयति, न तु भग्नतया।
