Sutram IDE

A full-screen editor and runner that ships with the language — and depends on nothing.

The point: Python's IDLE is a Python program, so it needs a Python interpreter. The Sutram IDE is a single native binary written in the same hand-written NASM as the compiler. No Python, no runtime, no toolkit, no interpreter — one executable that runs the moment it exists.

Install

It comes with the language. Run the normal installer and it is placed alongside the compiler, with a menu entry:

./install.sh            # installs sutram, sutram-ide, language packs, examples
sutram-ide examples/01_hello.sm

Or launch Sutram IDE from your applications menu.

Keys

KeyAction
Ctrl-RRun — compile and execute the buffer; output appears in the pane below
Ctrl-SSave to the current file
Ctrl-ZUndo — step back one edit, up to 4096 edits deep
Ctrl-LLoad a file (prompts on the status line)
Ctrl-TOpen the interactive shell pane — type a statement, press Enter, see it run; the session accumulates
Ctrl-EBrowse examples — each press loads the next examples/*.sm, wrapping at the end
Ctrl-QQuit
Arrows / Home / EndMove the cursor
Enter, BackspaceEdit — it is a normal text editor

The screen

 row 1            title
 rows 2..R-6      your code, with line numbers and syntax highlighting
 row R-5          Output
 rows R-4..R-1    what your program printed
 row R            file name, modified marker, key hints

Syntax highlighting

Keywords in magenta, strings in green, numbers in cyan, comments in grey — for the current keyword set, including the newer additions (kosh, dasham, guna, bhavana, rachana, ayojan, kuru, pankti).

How Run works

The buffer is written to a temporary .sm file, the compiler is invoked on it, and the resulting program is executed — both their output captured into the pane. The compiler is located in this order, so the IDE works whether you launch it from the source tree or from the app menu:

  1. ./sutram_compiler (running inside the source tree)
  2. sutram (the installed command, from your PATH)
