સૂત્રમ્ પુસ્તક

પ્રસ્તાવના. Sutram એક પ્રોગ્રામિંગ ભાષા છે જેના કીવર્ડ્સ સંસ્કૃત છે - માત્ર શણગાર માટે નહીં, પરંતુ એક ડિઝાઇન પ્રતિબદ્ધતા તરીકે. તેનું નામ, Sutram, એટલે સૂત્ર: પાનિનિની Ashtadhyayi નું સંક્ષિપ્ત નિયમ-સ્વરૂપ, જે વિશ્વનું પ્રથમ ઔપચારિક વ્યાકરણ છે. તેની સ્ટાન્ડર્ડ લાઇબ્રેરી ભારતીય ગાણિતિક પરંપરાને સીધી રીતે અમલમાં મૂકે છે - Pingala નું binary અને Meru-prastara, Aryabhata નું kuttaka, Bhaskara નું chakravala. અને કમ્પાઇલર પોતે જ આત્મનિર્ભર છે: એક હાથથી લખેલી એસેમ્બલી ફાઇલ જે નેટિવ મશીન કોડ બનાવે છે, જેમાં તમારે કોઈ રનટાઇમ કે ટૂલચેનની જરૂર પડતી નથી. આ પુસ્તક ભાષાને શરૂઆતથી શીખવે છે. દરેક ઉદાહરણ વાસ્તવિક કોડ છે જે કમ્પાઇલ થાય છે અને રન થાય છે, અને ભાષા વિશેનો દરેક દાવો તમે જાતે ચકાસી શકો છો.
💡 વાપરવાની રીત: કેસરી ટપકાં વાળા શબ્દ પર માઉસ ફેરવો — તેનો સંસ્કૃત શબ્દ અને English અર્થ તરત દેખાશે. (મોબાઈલમાં શબ્દ પર ટેપ કરીને રાખો. છાપેલા પેજ માટે દરેક પ્રકરણના અંતે કોષ્ટક છે.)

સંસ્કૃત કૂટશબ્દ. નેટિવ મશીન કોડ. દરેક ભાષાને જોડતો એક દોરો.

1. સૂત્રમ્ એટલે શું? (What is Sutram?)

સૂત્રમ્ (सूत्रम्) એટલે "દોરો" — બધું જોડનાર દોરો. સૂત્રમ્ એક કાર્યક્રમિંગ ભાષા છે: તેના કૂટશબ્દ સંસ્કૃતમાંથી આવે છે, તેનો સંકલક શુદ્ધ એસેમ્બલીમાં લખાયો છે, અને તે સીધી x86-64 મશીન કોડ બને છે. ઇન્ટરપ્રીટર નથી, વર્ચ્યુઅલ મશીન નથી, રનટાઇમ લાઇબ્રેરી નથી.

કેમ શીખવું?

1. પાયથોન જેવી સરળતા, C જેવી ઝડપ. તમે ચોખ્ખા સંસ્કૃત કૂટશબ્દ સાથે વાંચી શકાય એવો કોડ લખો; સંકલક નાની નેટિવ બાઇનરી બનાવે — હાથે લખેલી એસેમ્બલી ઝડપે ચાલે.

2. બધું દેખાય. સંકલક એક વાંચી શકાય એવી એસેમ્બલી ફાઇલ (~9000 લાઇન) — અસલી સંકલક કેવી રીતે કામ કરે તે જોઈ શકાય.

3. તમારી ભાષા, તમારા શબ્દ. ભાષા સંકુલ સાથે દરેક કૂટશબ્દ ગુજરાતીમાં લખી શકાય — જો (if), નહિંતર (else), કાર્ય (function), લખો (print).

જોઈએ: Linux x86-64 સિસ્ટમ (અથવા Windows પર WSL). બીજી ડિપેન્ડન્સી નહિ.

2. તમારો પહેલો કાર્યક્રમ (Your first program)

દરેક સૂત્રમ્ કાર્યક્રમ mukhya() થી શરૂ થાય. સેમીકોલન વૈકલ્પિક; બ્રેસ પણ વૈકલ્પિક; કોમેન્ટ // થી.

mukhya()
    likha("Namaste, Sutram!\n")
$ sutram namaste.sm namaste.bin
OK: compiled 90 bytes
$ ./namaste.bin
Namaste, Sutram!

3. ચલ અને અચલ (Variables and constants)

vitti થી વેરિએસલ જાહેર કરો. sutra થી અચલ:

mukhya()
    vitti x = 10
    x = x + 5
    likha(x)        // 15
    sutra pi = 314
    likha(pi / 100)  // 3
    likha("\n")

પહેલા પાંચ ચલ રજિસ્ટરમાં રહે — સંકલક જાતે જ ફાળવે.

4. સંકારક અને પ્રાથમિકતા (Operators and precedence)

સૂત્રમ્માં આખો સંકારક સેટ છે, ગણિતના નિયમો પ્રમાણે:

OperatorMeaningExample
+ - * / %arithmetic, modulo17 % 5 → 2
== != < > <= >=comparisonx >= 18
&& ||logical and / ora > 0 && b > 5
& | ^bitwise2 & 12 → 0
( ... )grouping(3 + 4) * 2 → 14
mukhya()
    vitti a = 3
    vitti b = 4
    likha((a + b) * 2)   // 14
    likha("\n")
    likha(17 % 5)         // 2
    likha("\n")
    likha(2 & 12)         // 0  (bitwise AND)
    likha("\n")

5. નિર્ણય: yadi / anyatra (Decisions (if / else))

yadi (જો) શરત સાચી હોય તો ચલાવે; anyatra (નહિંતર) નહિંતર. ઘણી શરતો માટે guna (switch):

mukhya()
    vitti mulya = 0
    yadi (mulya > 0) {
        likha("Positive\n")
    } yadi (mulya < 0) {
        likha("Negative\n")
    } anyatra {
        likha("Zero\n")
    }
mukhya()
    vitti divasa = 3
    guna (divasa) {
        bhavana 1: { likha("Somvaar\n") }
        bhavana 2: { likha("Mangalvaar\n") }
        bhavana 3: { likha("Budhvaar\n") }
        anyatra: { likha("Anyo divaah\n") }
    }

6. પુનરાવર્તન: punaravartana, yavat, krama, uddeshya (Loops)

mukhya()
    punaravartana i = 1 to 5 {
        likha(i)
        likha(" ")   // 1 2 3 4 5
    }
    likha("\n")
mukhya()
    vitti yogam = 0
    punaravartana i = 1 to 100 {
        yadi (i > 10) { krama }
        yadi (i % 2 == 0) { uddeshya }
        yogam = yogam + i
    }
    likha(yogam)     // 25
    likha("\n")
1 થી 10 સુધી એકી સંખ્યાનો સરવાળો: જવાબ 25.

7. ફલન: prakriya (Functions)

prakriya vishalya(mulya)
    pratiyati mulya * mulya

mukhya()
    vitti phalam = vishalya(7)
    likha(phalam)     // 49
    likha("\n")

રિકર્ઝન સીધું કામ કરે:

prakriya fib(n) {
    yadi (n < 2) { pratiyati n }
    pratiyati fib(n - 1) + fib(n - 2)
}

mukhya()
    likha(fib(10))     // 55
    likha("\n")

8. પંક્તિ: pankti (Arrays)

પંક્તિ = "હરોળ". pankti થી પંક્તિ જાહેર કરો:

mukhya()
    pankti tarika[5]
    punaravartana i = 0 to 5 {
        tarika[i] = i * i
    }
    likha(tarika[4])     // 16
    likha("\n")

9. નિવેશ: grahan (Input)

નવી સુવિધા! grahan() (ગ્રહણ = લેવું) વપરાશકર્તા પાસેથી સંખ્યા વાંચે — હવે સૂત્રમ્ કાર્યક્રમ ઇન્ટરેક્ટિવ!

mukhya()
    likha("એક સંખ્યા આપો: ")
    vitti x = grahan()
    likha("તમે આપ્યું: ")
    likha(x)
    likha("\n")

14. નવા લક્ષણો: v22 (New features)

ટિપ્પણીઓ (Comments)

કાર્યક્રમમાં ટિપ્પણી લખવાની બે રીતો છે — # (હેશ) અને // (ડબલ સ્લેશ)। સંકલક આને સંપૂર્ણપણે અવગણે છે.

# આ હેશ ટિપ્પણી છે
vitti x = 10  # કોડ પછી પણ લખી શકાય
// આ સ્લેશ ટિપ્પણી છે
likha(x)

સંયુક્ત સોંપણી (Compound Assignment)

vitti x = 100
x += 50   # 150
x -= 30   # 120
x *= 2    # 240
x /= 4    # 60
x %= 7    # 4

વૃદ્ધિ / ઘટાડો (++ / --)

vitti n = 5
n++      # n = 6
n--      # n = 5

શબ્દમાળા જોડાણ (String Concatenation)

સંકલન-સમયે જ શબ્દમાળાઓ અને સંખ્યાઓ જોડાઈ જાય છે:

likha("નમસ્તે " + "દુનિયા\n")
likha("જવાબ: " + 42 + "\n")
likha(7 + " દિવસ\n")

lkhb() — નવી કડી વિના છાપવું

likha() સંખ્યા પછી નવી કડી મૂકે છે; lkhb() નથી મૂકતું — કોષ્ટકો માટે:

punaravartana i = 1 to 5 {
    lkhb(i)
    likha(" ")
}

ઘટતા પુનરાવર્તન (Descending Loops)

શરૂઆતનું મૂલ્ય અંતિમ મૂલ્ય કરતાં મોટું હોય તો, ગણતરી આપોઆપ ઊતરે છે:

punaravartana i = 5 to 1 {
    lkhb(i)
    likha(" ")
}    # પરિણામ: 5 4 3 2 1

15. તકનીકી શબ્દકોશ (Technical Glossary) (Technical glossary)

આ પુસ્તકમાં વપરાયેલા તકનીકી શબ્દોના પ્રમાણભૂત ગુજરાતી રૂપ — અને તેનું કારણ:

Program → કાર્યક્રમ — કાર્ય (કામ) + ક્રમ (ક્રમ) = ક્રમબદ્ધ કામની યોજના. ગુજરાતી પાઠ્યપુસ્તકોમાં "પ્રોગ્રામ"ને બદલે વપરાતો પ્રમાણભૂત શબ્દ.

Compiler → સંકલક — સંકલન (એકત્ર કરી તૈયાર કરવું) કરનાર: સ્રોત-કોડને યંત્ર-કોડમાં બદલનાર અનુવાદક.

Computer → સંગણક — ગણતરી કરનારું યંત્ર. ગુજરાત સરકારના પાઠ્યપુસ્તકો અને સરકારી દસ્તાવેજોમાં પ્રમાણભૂત શબ્દ.

Keyword → કૂટશબ્દ — કૂટ (code) + શબ્દ. ભાષા માટે અનામત રાખેલા ખાસ શબ્દો, જેમ કે mukhya, vitti.

Variable → ચલ — પ્રોગ્રામના અમલ દરમિયાન જેની કિંમત બદલાઈ શકે છે તેવા નામવાળા મેમરી લોકેશન માટે ગુજરાતી ગણિત અને કમ્પ્યુટર વિજ્ઞાનના પાઠ્યપુસ્તકોમાં વપરાતો આ પ્રમાણભૂત શબ્દ છે.

Constant → અચલ — ચલનો સીધો સમકક્ષ શબ્દ, જેનો ઉપયોગ એવી નિશ્ચિત કિંમત માટે થાય છે જે બદલાતી નથી. "constant" માટે સ્થિરાંક શબ્દનો પણ વ્યાપકપણે ઉપયોગ થાય છે, ખાસ કરીને ગણિતમાં.

Function → ફલન — નિવેશમાંથી પરિણામનો નિયમ. ગણિતમાં જેમ "f(x)" ને ફલન કહીએ છીએ તેમ જ, કમ્પ્યુટર વિજ્ઞાનમાં પણ આ જ પ્રમાણભૂત શબ્દ છે.

Loop → પુનરાવૃત્તિ — પુનઃ + આવૃત્તિ (ફરી આવવું): વારંવાર ચાલતો કોડ. "પુનરાવર્તન" માટેનો સ્વીકૃત ગુજરાતી શબ્દ.

Array → સારણી — પંક્તિસર ગોઠવેલા મૂલ્યોનો સમૂહ. સૂત્રમ્ માં આ માટે pankti (પંક્તિ) કૂટશબ્દ છે.

Memory → સ્મૃતિ — માહિતી સંગ્રહવાનું સ્થાન. "મેમરી" માત્ર ઉચ્ચાર છે, અર્થ આપતો નથી.

Machine Code → યંત્ર-કોડ — CPU સીધો ચલાવી શકે તેવો દ્વિઆધારી કોડ. સૂત્રમ્ સીધા આ પર જ સંકલિત થાય છે.

String → સૂત્ર — અક્ષરોની માળા. સંસ્કૃતમાં સૂત્રનો શાબ્દિક અર્થ એ જ દોરો — એટલે જ ભાષાનું નામ સૂત્રમ્ છે!

Error → ભૂલ — કાર્યક્રમમાં થયેલી ભૂલ; સંકલક તેને પંક્તિ-નંબર સાથે બતાવે છે. "દોષ" શબ્દ પણ વપરાય છે.

Debugging → દોષસુધારો — દોષ (bug) શોધીને સુધારવાની પ્રક્રિયા.

Language → ભાષા — પ્રોગ્રામિંગ ભાષા: જેમાં માણસ સંગણકને આદેશ આપે છે.

16. સંસ્કૃત મૂળ: તમારી ભાષામાં જીવંત શબ્દ (Sanskrit roots)

17. વિન્ડોઝ પર સ્થાપન — સંપૂર્ણ માર્ગદર્શિકા

સૂત્રમ્ વિન્ડોઝને લિનક્સની જેમ જ પ્રથમ-શ્રેણીનું લક્ષ્ય ગણે છે. અગાઉનાં બધાં પ્રકરણો એ જ રીતે કામ કરે છે; ફક્ત સ્થાપનનું પગલું બદલાય છે, અને તે જ આ પ્રકરણમાં પૂરું સમજાવ્યું છે.

17.1 તમને શું મળે છે

  • sutram.exe — સંકલક, જે મૂળ Win64 કાર્યક્રમ (PE32+) છે.
  • સંકલિત કાર્યક્રમો ખરેખરા વિન્ડોઝ કાર્યક્રમો છે, સ્ક્રિપ્ટ નહીં.
  • WSL, લિનક્સ VM, પાયથન કે C રનટાઇમની જરૂર નથી.
  • એક જ સંકલક સ્રોત માંથી વિન્ડોઝ અને લિનક્સ બંને સંકલક બને છે, તેથી ભાષાનું વર્તન બંને પર સરખું છે.

17.2 જરૂરિયાતો

  • વિન્ડોઝ 10 કે 11, 64-બિટ.
  • સામાન્ય વપરાશ માટે બીજું કંઈ નહીં. NASM ફક્ત ત્યારે જોઈએ જ્યારે તમે સંકલક જાતે બનાવો.

17.3 સ્થાપન — રીત અ: જાદુઈ સ્થાપક (ભલામણ)

  1. Sutram-Setup.exe મેળવો.
  2. તેના પર ડબલ-ક્લિક કરો. નવા કાર્યક્રમ માટે વિન્ડોઝ SmartScreen ચેતવણી બતાવી શકે: More info → Run anyway પસંદ કરો.
  3. જાદુઈ સ્થાપક ગંતવ્ય ફોલ્ડર પૂછશે. ડિફોલ્ટ C:\Program Files\Sutram છે. તે સ્વીકારો, અથવા Browse થી પોતાનું પસંદ કરો.
  4. કોઈ પણ ફોલ્ડરથી sutram લખવું હોય તો “Add Sutram to PATH” પસંદ કરો. આ ભલામણ કરેલું છે.
  5. ઈચ્છો તો Start Menu પ્રવેશ અને Desktop શોર્ટકટ પસંદ કરો.
  6. Install દબાવો. પૂરું થાય એટલે બંધ કરો.

ત્યારબાદ સૂત્રમ્ Apps & Features માં નોંધાય છે, તેથી પછી તમે Settings થી સમારકામ, અદ્યતન કે અનઇન્સ્ટોલ કરી શકો.

17.4 સ્થાપન — રીત બ: પોર્ટેબલ ફોલ્ડર

  1. sutram-windows-native.zip ગમે ત્યાં ખોલો, જેમ કે C:\Sutram.
  2. ફોલ્ડર સાથે રાખો — ભાષા-સંકુલ sutram.exe પાસે lang\ માં રહે છે.
  3. તે જ ફોલ્ડરમાં ટર્મિનલ ખોલો (Shift + જમણું-ક્લિક → Open in Terminal).
  4. ઈચ્છો તો એક વાર install.bat ચલાવો, જે ફોલ્ડરને PATH માં ઉમેરે છે.

17.5 સ્થાપન — રીત ક: સ્રોતમાંથી નિર્માણ

વિકાસકર્તાઓ માટે. NASM અને PE-સક્ષમ લિંકર (GNU ld, MSVC કે lld-link) જોઈએ:

nasm -f win64 -dWINDOWS -I. src\sutram_compiler.asm -o sutram.obj
ld -mi386pep --entry=_start -o sutram.exe sutram.obj

જાદુઈ સ્થાપક પણ બનાવવો હોય તો MinGW GCC અને PowerShell જોઈએ; સ્ક્રિપ્ટ windows\ માં છે (BUILD-WINDOWS-SETUP.cmd ચલાવો).

17.6 PATH સમજો

PATH એ ફોલ્ડરોની યાદી છે જે વિન્ડોઝ કમાન્ડ લખતી વખતે શોધે છે. જો સૂત્રમ્નું ફોલ્ડર PATH માં હોય તો તમે ગમે ત્યાંથી sutram લખી શકો; નહીં તો પૂરો પાથ લખવો પડે અથવા તે જ ફોલ્ડરમાં રહેવું પડે.

ચકાસો: નવું ટર્મિનલ ખોલી sutram --version ચલાવો. આવૃત્તિ દેખાય તો PATH બરાબર છે. ન દેખાય તો PATH વિકલ્પ સાથે સ્થાપક ફરી ચલાવો, અથવા sutram.exe જ્યાં છે તે ફોલ્ડરમાંથી ચલાવો.

17.7 તમારો પહેલો વિન્ડોઝ કાર્યક્રમ

ફાઇલ namaste.sm બનાવો:

# મારો પહેલો વિન્ડોઝ કાર્યક્રમ
mukhya()
    likha("નમસ્તે, વિન્ડોઝ!")

સંકલન કરો અને ચલાવો:

sutram.exe namaste.sm namaste.exe
namaste.exe

પરિણામ:

નમસ્તે, વિન્ડોઝ!

આઉટપુટનું નામ લક્ષ્ય નક્કી કરે છે: .exe થી વિન્ડોઝ કાર્યક્રમ, .bin થી લિનક્સ. એક સંકલક, બે લક્ષ્ય.

17.8 બનેલા .exe માં શું હોય છે

સંકલિત કાર્યક્રમ એક PE32+ ખંડ છે જેમાં હોય છે:

[PE શીર્ષકો][નાનું રનટાઇમ][તમારો સંકલિત કોડ]

રનટાઇમ શરૂઆતમાં પ્રક્રિયા-પર્યાવરણ બ્લોકમાં ચાલીને તેની નિકાસ-સારણી વાંચીને kernel32 શોધી લે છે, તેથી કાર્યક્રમમાં કોઈ આયાત-સારણી કે બાહ્ય આધાર નથી. તે આઉટપુટ, ઇનપુટ અને નિકાસને WriteFile, ReadFile અને ExitProcess પર લઈ જાય છે. સૂત્રમ્થી બનેલા .exe ચલાવવા કંઈ પણ સ્થાપવું પડતું નથી.

17.9 વિન્ડોઝ પર ભાષા-સંકુલ

સૂત્રમ્ બે જગ્યાએ જુએ છે: વર્તમાન ફોલ્ડર પ્રમાણે lang\<name>.lang, પછી %USERPROFILE%\.local\share\sutram\lang\. સંકુલ બીજી જગ્યાએ રાખો તો તે ગમે તે ફોલ્ડરથી કામ કરશે.

sutram.exe --lang gujarati prog.sm out.exe

દસ સંકુલ: બંગાળી, ગુજરાતી, હિન્દી, કન્નડ, મલયાલમ, મરાઠી, ઓડિયા, પંજાબી, તમિલ, તેલુગુ. કૂટશબ્દોની દેવનાગરી જોડણી પણ સ્વીકાર્ય છે.

17.11 પરિયોજનાઓ ક્યાં રાખવી

ગમે ત્યાં. બે ટેવો મુશ્કેલી બચાવે છે: ઘણા ઊંડા પાથ ટાળો, અને સ્પેસવાળા પાથને અવતરણમાં રાખો — sutram.exe "C:\My Files\a.sm" "C:\out\a.exe". યુનિકોડ ફોલ્ડર નામો ચાલે છે; સંકલક ફાઇલો વિન્ડોઝ API થી ખોલે છે.

17.13 અદ્યતન અને અનઇન્સ્ટોલ

અદ્યતન: નવું Sutram-Setup.exe ચલાવો — તે હાલની સ્થાપન ઓળખીને સુરક્ષિત રીતે બદલે છે. દૂર કરવા: Settings → Apps → Installed apps → Sutram → Uninstall. અનઇન્સ્ટોલર ફક્ત તેની સ્થાપિત ફાઇલો દૂર કરે છે અને તમારી બનાવેલી ફાઇલો છોડી દે છે.

17.15 વિન્ડોઝ પર હજી શેષ

હાલ ચાલે છે: સંકલન, likha અને shabda, ગણિત, ચલ, yadi/anyatra, yavat, punaravartana, krama/uddeshya, છ દલીલો સુધીનાં ફલન, પુનરાવર્તન, વહેલું પ્રત્યાગમન, બ્લોક ટિપ્પણીઓ, ભાષા-સંકુલ, ત્રુટિ-સંદેશ.

વિન્ડોઝ પર કીબોર્ડ ઇનપુટ (grahan) હવે કામ કરે છે: બનેલી .exe લિનક્સ સિસ્ટમ કૉલને બદલે એમ્બેડેડ રનટાઇમ (ReadFile) દ્વારા વાંચે છે. પંક્તિ (pankti) અને રચના (rachana) VirtualAlloc દ્વારા સ્મૃતિ લે છે. હજુ પોર્ટ નથી થયા: નેટવર્ક બિલ્ટ-ઇન્સ. ઇન્ટરેક્ટિવ REPL ઇમ્પ્લિમેન્ટ થઈ ગયું છે અને અસલ Windows મશીન પર ચેક થવાની રાહ જોઈ રહ્યું છે.

17.16 દર્શન — અપરિવર્તિત

સંકલક એક શુદ્ધ-NASM સ્રોત રહે છે, જેમાં C, પાયથન કે રનટાઇમનો આધાર નથી; સંસ્કૃત ભાષાનું કેન્દ્ર રહે છે અને દરેક ભારતીય ભાષા માટે મૂળ શબ્દો છે; બનેલા કાર્યક્રમો મૂળ મશીન-કોડ હોય છે, કદી વ્યાખ્યાયિત નહીં; અને અંતિમ વપરાશકર્તાને કોઈ ટૂલચેનની જરૂર નથી. સ્થાપક ફક્ત પેકેજિંગ છે — તે ભાષાનો ભાગ નથી.

18. નવું શું છે — વર્તમાન ભાષા

આ પ્રકરણ પુસ્તકના બાકીના ભાગ પછી ઉમેરવામાં આવ્યું હતું. તેમાંની દરેક વસ્તુ આજે ભાષાનો ભાગ છે અને માત્ર એક જ વાર કમ્પાઈલ કરવાને બદલે જાણીતા જવાબો સાથે ચકાસવામાં આવી છે. જો અગાઉનું પ્રકરણ અહીં કોઈ વાતનો ઉલ્લેખ ન કરતું હોય, તો આ પ્રકરણ વધુ વર્તમાન છે.

ફ્લોટિંગ-પોઈન્ટ નંબર્સ — દશમ

ચલ 64-bit IEEE-754 ફ્લોટિંગ-પોઈન્ટ નંબર ધરાવી શકે છે. તેને દશમ સાથે જાહેર કરો; દશાંશ ચિહ્નવાળો લિટરલ આપમેળે ફ્લોટ બની જાય છે.

ફ્લોટ્સ પૂર્ણાંકો સાથે ભળે છે (પૂર્ણાંક પ્રમોટ થાય છે), ચારેય અંકગણિત ઓપરેટરો અને તમામ છ સરખામણીઓને સપોર્ટ કરે છે, અને છ દશાંશ સ્થાનો સાથે પ્રિન્ટ થાય છે. ફંક્શન્સ ફ્લોટ રિટર્ન કરી શકે છે — કમ્પાઈલર તે તેઓ જે રિટર્ન કરે છે તેમાંથી અનુમાનિત કરે છે.

વધારી શકાય તેવા એરે — કોશ

સામાન્ય એરેનું કદ નિશ્ચિત હોય છે. કોશ વધે છે: તે નાની ક્ષમતાથી શરૂ થાય છે અને જરૂરિયાત મુજબ બમણું થાય છે.

ક્ષમતા એ લંબાઈ નથી. 4 ક્ષમતા સાથે જાહેર કરાયેલ કોશની ક્ષમતા 4 છે પરંતુ લંબાઈ 0 છે, તેથી જ્યાં સુધી કંઈક પુશ ન થાય ત્યાં સુધી ઇન્ડેક્સ 0 બાઉન્ડ્સની બહાર છે. આ લોકોને એકવાર મૂંઝવણમાં મૂકે છે; તે ઇરાદાપૂર્વક છે, અને તે જ ઇન્ડેક્સિંગને સુરક્ષિત બનાવે છે.

ટાઈપ્ડ એરે — કોશ દશમ

ફ્લોટ્સ ધરાવવા માટે કોશ જાહેર કરી શકાય છે. તેમાં પુશ કરાયેલા પૂર્ણાંક મૂલ્યો પ્રમોટ થાય છે, અને તેના તત્વો દરેક જગ્યાએ ફ્લોટ્સ તરીકે વર્તે છે.

ટાઈપ્ડ ફંક્શન પેરામીટર્સ

ફંક્શનને ચોક્કસ પ્રકારના દલીલની જરૂર પડી શકે છે, અને કમ્પાઈલર તેને તપાસે છે.

ટાઈપ્ડ ફ્લોટ એરે પોઇન્ટર તરીકે પસાર થાય છે, તેથી ઇન્ડેક્સ કરેલ લખાણ કૉલરને દેખાય છે — ફંક્શન તમારા માટે એરે ભરી શકે છે. પરંતુ તેને વધારવાની મંજૂરી નથી: પેરામીટર પર કોશ_પુશ કૉલ કરવાનો ઇનકાર નામવાળા ભૂલ સાથે કરવામાં આવે છે, કારણ કે પોઇન્ટર બાય વેલ્યુ પસાર થાય છે અને કૉલર પાસે જૂનું પોઇન્ટર રહી જશે. આ એક ઇરાદાપૂર્વકની સલામતી સીમા છે, ખૂટતી સુવિધા નથી.

સ્ટાન્ડર્ડ લાઈબ્રેરી

કમ્પાઈલર સાથે પંદર મોડ્યુલો આવે છે. આયુજન સાથે એક આયાત કરો. તેઓ અંકગણિત અને નંબર થિયરી; સૉર્ટિંગ અને ટેક્સ્ટ; પિંગળાની છંદશાસ્ત્ર; આર્યભટ્ટ અને ભાસ્કરનું ગણિત; પાઇ, સાઇન, કોસાઇન અને વર્ગમૂળ માટે કેરળ શાળાની શ્રેણી; આંકડાશાસ્ત્ર; ન્યુમેરિકલ કેલ્ક્યુલસ — એકીકરણ, ડેરિવેટિવ્સ અને બહુપદી મૂળ; મેટ્રિક્સ અને નિર્ણાયકો સાથે રેખીય બીજગણિત; અને ફાઇલ વાંચવા અને લખવાને આવરી લે છે.

પ્રયાસ કરો: વારસાગત મોડ્યુલો વાસ્તવિક ગણિતની ગણતરી કરે છે — 61 નું ચક્રવાળ x વર્ગ માઇનસ 61 y વર્ગ બરાબર 1 નો સૌથી નાનો ઉકેલ આપે છે, જે x = 1766319049, y = 226153980 છે. તે 7મી સદીની પદ્ધતિ છે, જે સાચા જવાબ સામે ચકાસવામાં આવી છે.

સૂત્રમ IDE

ભાષા સાથે ઇન્સ્ટોલ કરેલ છે. એક જ નેટિવ પ્રોગ્રામ — કોઈ Python નહીં, કોઈ ઇન્ટરપ્રિટર નહીં — લાઇન નંબરો અને સિન્ટેક્સ હાઇલાઇટિંગ સાથે કોડ એડિટર સાથે; તમે જે લખ્યું છે તેને કમ્પાઇલ કરવા અને ચલાવવા માટે Ctrl-R, આઉટપુટ નીચે બતાવેલ છે; ઉદાહરણ પ્રોગ્રામ્સને એક સમયે બ્રાઉઝ કરવા માટે Ctrl-E; ઇન્ટરેક્ટિવ શેલ માટે Ctrl-T જ્યાં તમે સ્ટેટમેન્ટ ટાઇપ કરો છો, Enter દબાવો છો, અને તેને ચાલતું જુઓ છો, સત્ર અગાઉની લાઇનો યાદ રાખે છે જેથી તમે એક સમયે એક પગલું બનાવી શકો; અને સાચવવા માટે Ctrl-S, લોડ કરવા માટે Ctrl-L, બહાર નીકળવા માટે Ctrl-Q.

Windows પર IDE હજી ઉપલબ્ધ નથી; તેના બદલે ઇન્ટરેક્ટિવ શેલનો ઉપયોગ કરો.

ઝડપ, દાવો કરવાને બદલે માપવામાં આવે છે

કમ્પાઈલર ચલ મૂલ્યોને મેમરીને બદલે પ્રોસેસર રજિસ્ટરમાં રાખે છે. પ્રતિનિધિ ન્યુમેરિકલ પ્રોગ્રામ પર આ તાજેતરના રાઉન્ડ્સમાં લગભગ 1.2 ગણી માપેલી ઝડપ ઉત્પન્ન કરે છે, અને ટાઈટ ઈન્ટિજર લૂપ પર જનરેટ થયેલ કોડ 13 સૂચનાઓથી 5 સુધી ગયો — 4.9 ગણી માપેલી. આ વિભાગમાં દરેક દાવો સમાન મશીન પર પહેલાં અને પછી માપવામાં આવ્યો હતો, અંદાજવામાં આવ્યો ન હતો.

પ્રોજેક્ટ શેના વિશે સાવચેત છે

ચાર મેમરી-ભ્રષ્ટાચાર બગ્સ મળી આવ્યા અને ઠીક કરવામાં આવ્યા, દરેક હવે કાયમી પરીક્ષણ દ્વારા આવરી લેવામાં આવે છે. કમ્પાઈલરને 160 પરીક્ષણો અને બાર કોડ-શેપ ગેટ્સ દ્વારા તપાસવામાં આવે છે જે ખાતરી કરે છે કે આપેલ રચના કેટલો કોડ ઉત્પન્ન કરવાની મંજૂરી છે. જ્યાં પ્રોજેક્ટ કંઈક ચકાસી શકતો નથી — વાસ્તવિક Windows મશીન પર હજુ સુધી Windows ચલાવવામાં આવ્યું નથી — તે અન્યથા સૂચવવાને બદલે સ્પષ્ટપણે કહે છે.

A typed function parameter

prakriya mean(kosh dasham xs) {
    dasham s = 0.0
    vitti i = 0
    yavat (i < kosh_len(xs)) {
        s = s + xs[i]
        i = i + 1
    }
    pratiyati s / kosh_len(xs)
}
