The three things this project must not claim.
  • Memory safety — there is no ownership model. The charter says specify the rules before claiming the guarantee, and that has not happened.
  • Windows support — the sources exist and are complete-looking, but no run has ever produced a verified executable. "It builds and the headers are right" is not "it works".
  • Performance superiority — the compiler emits native code, but no benchmark has shown it faster than anything. Native output is not, by itself, a speed claim.
The standard the project now holds itself to: a verified partial beats a claim. Every partner round is built and run here before it is merged, and every document that states a number is checked against a measurement. Where something is untested, it is labelled untested rather than left to read as done.
