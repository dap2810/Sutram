॥ सूत्रम् ॥

சூத்திரம் புத்தகம்

முன்னுரை. Sutram என்பது ஒரு ப்ரோக்ராமிங் மொழி, இதன் கீவேர்டுகள் சமஸ்கிருதத்தில் உள்ளன - இது வெறும் அலங்காரத்திற்காக அல்ல, ஒரு டிசைன் கமிட்மெண்டாக. இதன் பெயரான Sutram என்றால் 'சூத்திரம்' என்று அர்த்தம்: உலகின் முதல் ஃபார்மல் கிராமரான பாணினியின் Ashtadhyayi-ல் வரும் சுருக்கமான விதி-வடிவம். இதன் ஸ்டாண்டர்ட் லைப்ரரி இந்திய கணித மரபை நேரடியாகச் செயல்படுத்துகிறது - பிங்கலரின் பைனரி மற்றும் Meru-prastara, ஆரியபட்டாவின் kuttaka, பாஸ்கராவின் chakravala. மேலும் இதன் கம்பைலரே தன்னிறைவானது: நீங்கள் எந்த ரன்டைமும், டூல்கெயினும் இல்லாமல், சொந்தமாக நேட்டிவ் மெஷின் கோடை உருவாக்கும் ஒரே ஒரு கைப்பட எழுதப்பட்ட அசெம்பிளி ஃபைல் இதில் உள்ளது. இந்தப் புத்தகம் இந்த மொழியை ஆரம்பத்திலிருந்தே கற்றுக்கொடுக்கிறது. இதில் உள்ள ஒவ்வொரு உதாரணமும் கம்பைல் ஆகி ஓடும் உண்மையான கோடாகும், மேலும் மொழியைப் பற்றிய ஒவ்வொரு தகவலையும் நீங்களே சரிபார்த்துக் கொள்ளலாம்.
💡 பயன்படுத்தும் முறை: குங்குமப் புள்ளியுள்ள சொல்லின் மேல் சுட்டியை வைக்கவும் — அதன் சமசுகிருதச் சொல்லும் English பொருளும் உடனே தெரியும். (அச்சுப் பக்கங்களுக்கு ஒவ்வோர் அத்தியாயத்தின் இறுதியிலும் அட்டவணை உள்ளது.)

சமஸ்கிருத குறிச்சொல்கள். நேடிவ் மெஷின் கோட். ஒவ்வொரு மொழியையும் இணைக்கும் ஒரு நூல்.

1. சூத்திரம் என்றால் என்ன? (What is Sutram?)

சூத்திரம் (सूत्रम्) என்றால் "நூல்" — எல்லாவற்றையும் இணைக்கும் நூல். சூத்திரம் ஒரு புரோகிராமிங் மொழி: இதன் குறிச்சொல்கள் சமஸ்கிருதத்திலிருந்து வருகின்றன, இதன் தொகுப்பி தூய அஸெம்பிளியில் எழுதப்பட்டுள்ளது, இது நேரடியாக x86-64 மெஷின் கோடாக மாற்றப்படுகிறது. இண்டர்பிரெட்டர் இல்லை, வர்சுவல் மெஷின் இல்லை, ரன்டைம் லைப்ரரி இல்லை.

ஏன் கற்க வேண்டும்?

1. பைத்தான் எளிமை, C வேகம். நீங்கள் சுத்தமான சமஸ்கிருத குறிச்சொல்களுடன் படிக்கக்கூடிய கோட் எழுதுகிறீர்கள்; தொகுப்பி ஒரு சிறிய நேடிவ் பைனரியை உருவாக்குகிறது — கையால் எழுதப்பட்ட அஸெம்பிளி வேகத்தில் இயங்குகிறது.

2. எல்லாம் தெரியும். தொகுப்பி ஒரு படிக்கக்கூடிய அஸெம்பிளி கோப்பு (~9000 வரிகள்) — உண்மையான தொகுப்பி எப்படி வேலை செய்கிறது என்று பார்க்கலாம்: லெக்ஸர் → பார்ஸர் → கோட் ஜெனரேட்டர் → ELF ரைட்டர்.

3. உங்கள் மொழி, உங்கள் வார்த்தைகள். மொழித் தொகுப்புகுடன் ஒவ்வொரு கீவேர்டையும் தமிழிலும் எழுதலாம் — எனில் (if), வரை (while), செயல் (function), எழுது (print).

தேவை: Linux x86-64 கணினி (அல்லது Windows-ல் WSL). வேறு டிபெண்டென்ஸி இல்லை — C கம்பைலரும் தேவையில்லை.

2. உங்கள் முதல் நிரல் (Your first program)

ஒவ்வொரு சூத்திரம் புரோகிராமும் mukhya() உடன் தொடங்குகிறது. செமிகோலன் விருப்பம்; ஒரு ஸ்டேட்மெண்டுக்கு பிரேஸும் விருப்பம்; கருத்துகள் // உடன்.

mukhya()
    likha("Namaste, Sutram!\n")
$ sutram namaste.sm namaste.bin
Siddh: 97 byte sankalit
$ ./namaste.bin
Namaste, Sutram!
தொகுப்பி முழுமையான ELF பைனரியை உருவாக்குகிறது — இந்த புரோகிராமுக்கு வெறும் 90 பைட். அதுதான் மொத்த நிரல்.

3. மாறிகள் மற்றும் மாறிலிகள் (Variables and constants)

vitti உடன் மாறி அறிவிக்கலாம். sutra உடன் மாறிலி:

mukhya()
    vitti x = 10
    x = x + 5
    likha(x)        // 15
    sutra pi = 314
    likha(pi / 100)  // 3
    likha("\n")

முதல் ஐந்து மாறிகள் ரிஜிஸ்டர்களில் இருக்கும் — தொகுப்பி தானாக ஒதுக்கும்.

4. இயக்கிகள் மற்றும் முன்னுரிமை (Operators and precedence)

சூத்ரத்தில் முழு இயக்கி தொகுப்பு உள்ளது, கணித விதிகளின்படி:

OperatorMeaningExample
+ - * / %arithmetic, modulo17 % 5 → 2
== != < > <= >=comparisonx >= 18
&& ||logical and / ora > 0 && b > 5
& | ^bitwise2 & 12 → 0
( ... )grouping(3 + 4) * 2 → 14
mukhya()
    vitti a = 3
    vitti b = 4
    likha((a + b) * 2)   // 14
    likha("\n")
    likha(17 % 5)         // 2
    likha("\n")
    likha(2 & 12)         // 0  (bitwise AND)
    likha("\n")

5. முடிவெடுத்தல்: yadi / anya (Decisions (if / else))

yadi (எனில்) ஷரத்து உண்மையெனில் இயக்கும்; anya (இல்லையெனில்) மற்றபடி. பல ஷரத்துகளுக்கு guna (switch):

mukhya()
    vitti mulya = 0
    yadi (mulya > 0) {
        likha("Positive\n")
    } yadi (mulya < 0) {
        likha("Negative\n")
    } anya {
        likha("Zero\n")
    }
mukhya()
    vitti divasa = 3
    guna (divasa) {
        bhavana 1: { likha("Somvaar\n") }
        bhavana 2: { likha("Mangalvaar\n") }
        bhavana 3: { likha("Budhvaar\n") }
        anya: { likha("Anyo divaah\n") }
    }

6. மடக்குகள்: chakra, yavat, krama, agrim (Loops)

mukhya()
    chakra i = 1 tak 5 {
        likha(i)
        likha(" ")   // 1 2 3 4 5
    }
    likha("\n")
mukhya()
    vitti yogam = 0
    chakra i = 1 tak 100 {
        yadi (i > 10) { krama }
        yadi (i % 2 == 0) { agrim }
        yogam = yogam + i
    }
    likha(yogam)     // 25
    likha("\n")
1 முதல் 10 வரை ஒற்றைப்படை எண்களின் கூட்டல்: விடை 25.

7. சார்புகள்: prakriya (Functions)

prakriya vishalya(mulya)
    prati mulya * mulya

mukhya()
    vitti phalam = vishalya(7)
    likha(phalam)     // 49
    likha("\n")

ரிகர்ஷன் நேரடியாக வேலை செய்யும்:

prakriya fib(n) {
    yadi (n < 2) { prati n }
    prati fib(n - 1) + fib(n - 2)
}

mukhya()
    likha(fib(10))     // 55
    likha("\n")

8. அணிகள்: mala (Arrays)

பங்க்தி = "வரிசை". mala உடன் அணி அறிவிக்கலாம்:

mukhya()
    mala tarika[5]
    chakra i = 0 tak 5 {
        tarika[i] = i * i
    }
    likha(tarika[4])     // 16
    likha("\n")

9. உள்ளீடு: grahan (Input)

புதிய ஃபீச்சர்! grahan() (கிரஹணம் = பெறுதல்) பயனரிடமிருந்து எண்ணை வாசிக்கும் — இப்போது சூத்திரம் நிரல்கள் இணைச்செயல்!

mukhya()
    likha("ஒரு எண் கொடுங்கள்: ")
    vitti x = grahan()
    likha("நீங்கள் கொடுத்தது: ")
    likha(x)
    likha("\n")
$ ./out.bin
ஒரு எண் கொடுங்கள்: 42
நீங்கள் கொடுத்தது: 42

14. புதிய அம்சங்கள்: v22 (New features)

குறிப்புகள் (Comments)

நிரலில் குறிப்பு எழுத இரண்டு வழிகள் — # (ஹாஷ்) மற்றும் // (இரட்டை ஸ்லாஷ்)। தொகுப்பி இவற்றை முழுமையாக புறக்கணிக்கிறது.

# இது ஹாஷ் குறிப்பு
vitti x = 10  # குறியீட்டுக்குப் பின்னும் எழுதலாம்
// இது ஸ்லாஷ் குறிப்பு
likha(x)

கூட்டு ஒதுக்கீடு (Compound Assignment)

vitti x = 100
x += 50   # 150
x -= 30   # 120
x *= 2    # 240
x /= 4    # 60
x %= 7    # 4

அதிகரிப்பு / குறைப்பு (++ / --)

vitti n = 5
n++      # n = 6
n--      # n = 5

சரம் இணைப்பு (String Concatenation)

தொகுக்கும் நேரத்திலேயே சரங்களும் எண்களும் இணைகின்றன:

likha("வணக்கம் " + "உலகம்\n")
likha("பதில்: " + 42 + "\n")
likha(7 + " நாட்கள்\n")

lkhb() — புதிய வரியில்லாமல் அச்சிடுதல்

likha() எண்ணுக்குப் பின் புதிய வரியை சேர்க்கிறது; lkhb() சேர்க்காது — அட்டவணைகளுக்கு:

chakra i = 1 tak 5 {
    lkhb(i)
    likha(" ")
}

இறங்கு மடக்குகள் (Descending Loops)

தொடக்க மதிப்பு இறுதி மதிப்பை விட பெரியதாக இருந்தால், எண்ணிக்கை தானாகக் குறையும்:

chakra i = 5 tak 1 {
    lkhb(i)
    likha(" ")
}    # வெளியீடு: 5 4 3 2 1

yantra() — இன்லைன் இயந்திரக் குறியீடு

மூல x86-64 பைட்டுகளை நேரடியாக உருவாகும் குறியீட்டில் சேர்க்கலாம்:

yantra("B8 3C 00 00 00")  # mov eax, 60
yantra("BF 2A 00 00 00")  # mov edi, 42
yantra("0F 05")            # syscall → exit(42)

grahan() மற்றும் உள்ளீட்டின் முடிவு

உள்ளீடு முடிந்தால் grahan() இப்போது -1 தருகிறது, இதனால் நிரல் சரியாக முடியும்:

vitti a = grahan()
yadi (a == -1) {
    likha("உள்ளீடு முடிந்தது\n")
    krama
}

v29 – v41

இந்த பதிப்பு எழுதப்பட்டதிலிருந்து, Sutram-ல் ternary operator, do-while loop, mala length மற்றும் bounds checking, ஆறு arguments வரையிலான functions, மற்றும் ஒரு standard library ஆகியவை சேர்க்கப்பட்டுள்ளன. இப்போது out-of-range mala index அமைதியாக data-வை corrupt செய்வதற்குப் பதிலாக, ஒரு தெளிவான error-ஐக் காட்டுகிறது. மேலும், Windows programs-ல் keyboard input வேலை செய்கிறது. கீழே உள்ள ஒவ்வொரு example-ம் இந்த project-ன் சொந்த test suite-ஆல் சரிபார்க்கப்பட்டுள்ளது.

Sutram ஒரு சிறிய ஸ்டாண்டர்ட் லைப்ரரியை வழங்குகிறது, அதை நீங்கள் yoj மூலம் சேர்த்துக்கொள்ளலாம். இந்த மாட்யூல் கம்பைல் செய்யும்போதே உங்கள் ப்ரோக்ராமில் இன்லைன் செய்யப்படுவதால், ரன்டைம் டிபென்டன்சி எதுவும் இல்லை - லைப்ரரி கோட் உங்கள் பைனரியின் ஒரு பகுதியாகவே மாறிவிடும். இன்று பன்னிரண்டு மாட்யூல்கள் கிடைக்கின்றன; முழுப் பட்டியல் docs/sutram-stdlib.html-இல் உள்ளது.

15. தொழில்நுட்பச் சொற்களஞ்சியம் (Technical Glossary) (Technical glossary)

இந்த நூலில் பயன்படுத்தப்படும் தொழில்நுட்பச் சொற்களின் நிலைத்த தமிழ் வடிவம் — மற்றும் அதற்கான காரணம்:

Program → நிரல் — கணினி செய்ய வேண்டிய பணிகளின் வரிசை. தமிழ்நாடு அரசு பாடநூல்களிலும் கணினி இதழ்களிலும் "program"-க்குப் பயன்படும் நிலைத்த சொல்.

Compiler → தொகுப்பி — மூல நிரலை இயந்திர மொழியாக மாற்றும் மொழிபெயர்ப்பான். "தொகுத்து" (ஒன்றாகச் சேர்த்து) உருவான சொல்.

Computer → கணினி — "கணித்தல்" (கணக்கிடுதல்) என்ற வேர்ச்சொல்லிலிருந்து உருவானது; அரசு ஆவணங்களிலும் பாடநூல்களிலும் நிலைத்த சொல்.

Keyword → குறிச்சொல் — மொழிக்கென ஒதுக்கப்பட்ட சிறப்புச் சொல், எ.கா. mukhya, vitti.

Variable → மாறி — மதிப்பு மாறக்கூடிய பெயரிடப்பட்ட நினைவக இடம். கணிதப் பாடநூல்களில் x, y மாறிகளுக்கு நிலைத்த சொல்.

Constant → மாறிலி — "மாறி"யின் இணைச்சொல் போல அமைந்தது: மாறாத மதிப்பு. "மாறா எண்" என்பதும் பயன்பாட்டில் உண்டு.

Function → சார்பு — உள்ளீட்டிலிருந்து வெளியீட்டின் விதி; கணிதத்திலிருந்து வந்த நிலையான சொல்.

Loop → மடக்கு — திரும்பத் திரும்ப இயங்கும் அமைப்பு; "மீள் சுற்று" என்பதும் வழக்கில் உண்டு.

Array → வரிசை — வரிசையாக அடுக்கிய மதிப்புகள். சூத்ரமில் இதற்கு mala (வரிசை/பங்க்தி) குறிச்சொல் உள்ளது.

Memory → நினைவகம் — தரவைச் சேமித்து வைக்கும் இடம்; "நினைவு" என்ற வேரிலிருந்து.

Machine Code → இயந்திர மொழி — CPU நேரடியாக இயக்கக்கூடிய இரும (binary) குறியீடு. சூத்திரம் நேரடியாக இதிலேயே தொகுக்கப்படுகிறது.

String → சரம் — எழுத்துகளின் தொடர்; "நூல்" என்பதன் இணைச்சொல். சமசுகிருதத்தில் "சூத்திரம்" என்றாலே நூல்/இழை — எனவே மொழியின் பெயரே சூத்திரம்!

Error → பிழை — நிரலில் ஏற்படும் தவறு; தொகுப்பி அதை வரிசை எண்ணுடன் காட்டும்.

Debugging → பிழைத்திருத்தம் — பிழையைக் கண்டறிந்து சரிசெய்யும் செயல்முறை.

Language → மொழி — நிரலாக்க மொழி: மனிதன் கணினிக்குக் கட்டளையிடும் முறை.

16. சமசுகிருத வேர்கள்: உங்கள் மொழியில் வாழும் சொற்கள் (Sanskrit roots)

சூத்ரமின் ஒவ்வொரு குறிச்சொல்லும் சமசுகிருத வேர் ஒன்றிலிருந்து வருகிறது — பல சொற்கள் தமிழிலும் அப்படியே வழக்கில் உள்ளன. நீங்கள் shunya என எழுதும்போது, அரபு வழியாக ஆங்கிலத்தின் zero ஆன அதே சொல்லைத் தொடுகிறீர்கள்.

குறிச்சொல்சமசுகிருத வேர் பொருள்உங்கள் மொழியில்
mukhyaமுகம் = முன்னால் உள்ளது, தலைமைதமிழ் "முக்கியம்" — அப்படியே!
vittiவித் = அறிதல்"வித்தகம்" (நிபுணத்துவம்) ஒப்புமை
ankaஅங்க = எண் குறியீடுதமிழ் "எண்" (தூய தமிழ்)
yadiயதி = எனில்தமிழ் "எனின் / எனில்"
anyaவேறு இடத்தில்"வேறு" என்பதுடன் ஒப்புமை
yavatஅளவுக்கு, வரைதமிழ் "வரை"
chakraமீண்டும் மீண்டும் வருதல்"மீள்சுற்று"; "புனரவர்த்தனை"
kramaஒழுங்கு, வரிசைதமிழ் "கிரமம்" — அப்படியே வழக்கில்!
prakriyaசெயலின் முறைதமிழ் "செயல்முறை" (மொழிபெயர்ப்பு)
purnaநிறைந்ததமிழ் "பூரணம்" — அப்படியே!
shunyaவெறுமை"பூஜ்யம்" — சமசுகிருதத்திலிருந்து; தூய தமிழ் "சுழி"
likhaஎழுதுதல்தமிழ் "எழுது" (தூய தமிழ் வேர்)
grahanபெறுதல், ஏற்றல்தமிழ் "ஏற்றல் / பெறுதல்"
malaவரிசை, கூட்டம்தமிழ் "வரிசை"
sutraநூல், இழைதமிழ் "சூத்திரம்" — கணிதச் சூத்திரம்!

17. விண்டோஸில் நிறுவல் — முழு வழிகாட்டி

சூத்திரம் விண்டோஸை லினக்ஸைப் போலவே முதன்மை இலக்காகக் கருதுகிறது. முந்தைய அத்தியாயங்கள் அனைத்தும் அதேபோல் செயல்படும்; நிறுவல் படி மட்டுமே மாறுகிறது, அதை இந்த அத்தியாயம் முழுமையாக விளக்குகிறது.

17.1 உங்களுக்குக் கிடைப்பது

  • sutram.exe — சொந்த Win64 நிரலாக (PE32+) உள்ள தொகுப்பி.
  • தொகுக்கப்பட்ட நிரல்கள் உண்மையான விண்டோஸ் செயலிகள், ஸ்கிரிப்ட்கள் அல்ல.
  • WSL, லினக்ஸ் VM, பைதான் அல்லது C இயக்கநேரம் தேவையில்லை.
  • ஒரே தொகுப்பி மூலத்திலிருந்து விண்டோஸ், லினக்ஸ் இரண்டும் உருவாகின்றன, எனவே மொழியின் நடத்தை இரண்டிலும் ஒன்றே.

17.2 தேவைகள்

  • விண்டோஸ் 10 அல்லது 11, 64-பிட்.
  • சாதாரண பயன்பாட்டுக்கு வேறு எதுவும் தேவையில்லை. தொகுப்பியை நீங்களே உருவாக்கினால் மட்டுமே NASM தேவை.

17.3 நிறுவல் — முறை அ: வழிகாட்டி (பரிந்துரை)

  1. Sutram-Setup.exe-ஐப் பெறவும்.
  2. அதை இரட்டை-கிளிக் செய்யவும். புதிய நிரலுக்கு விண்டோஸ் SmartScreen எச்சரிக்கை காட்டலாம்: More info → Run anyway தேர்ந்தெடுக்கவும்.
  3. வழிகாட்டி இலக்கு கோப்புறையைக் கேட்கும். இயல்புநிலை C:\Program Files\Sutram. அதை ஏற்கவும், அல்லது Browse மூலம் உங்கள் கோப்புறையைத் தேர்ந்தெடுக்கவும்.
  4. எந்தக் கோப்புறையிலிருந்தும் sutram எனத் தட்டச்சு செய்ய விரும்பினால் “Add Sutram to PATH”-ஐத் தேர்ந்தெடுக்கவும். இது பரிந்துரைக்கப்படுகிறது.
  5. விரும்பினால் Start Menu உள்ளீடு, Desktop குறுக்குவழி தேர்ந்தெடுக்கவும்.
  6. Install அழுத்தவும். முடிந்ததும் மூடவும்.

பின்னர் சூத்திரம் Apps & Features-இல் பதிவாகும், எனவே Settings-இலிருந்து பழுதுபார்த்தல், மேம்படுத்தல் அல்லது நீக்கம் செய்யலாம்.

17.4 நிறுவல் — முறை ஆ: எடுத்துச் செல்லக்கூடிய கோப்புறை

  1. sutram-windows-native.zip-ஐ எங்கும் திறக்கவும், எ.கா. C:\Sutram.
  2. கோப்புறையை ஒன்றாக வைத்திருங்கள் — மொழித் தொகுப்புகள் sutram.exe-க்கு அருகில் lang\-இல் உள்ளன.
  3. அதே கோப்புறையில் முனையத்தைத் திறக்கவும் (Shift + வலது-கிளிக் → Open in Terminal).
  4. விரும்பினால் install.bat-ஐ ஒருமுறை இயக்கவும் — அது கோப்புறையை PATH-இல் சேர்க்கும்.

17.5 நிறுவல் — முறை இ: மூலத்திலிருந்து உருவாக்கு

உருவாக்குநர்களுக்கு. NASM மற்றும் PE-திறன் கொண்ட இணைப்பி (GNU ld, MSVC, lld-link) தேவை:

nasm -f win64 -dWINDOWS -I. src\sutram_compiler.asm -o sutram.obj
ld -mi386pep --entry=_start -o sutram.exe sutram.obj

வழிகாட்டி நிறுவியையும் உருவாக்க வேண்டுமெனில் MinGW GCC மற்றும் PowerShell தேவை; ஸ்கிரிப்ட்கள் windows\-இல் உள்ளன (BUILD-WINDOWS-SETUP.cmd).

17.6 PATH-ஐப் புரிந்துகொள்ளுதல்

PATH என்பது நீங்கள் ஒரு கட்டளையைத் தட்டச்சு செய்யும்போது விண்டோஸ் தேடும் கோப்புறைகளின் பட்டியல். சூத்திரத்தின் கோப்புறை PATH-இல் இருந்தால் எங்கிருந்தும் sutram எனத் தட்டச்சு செய்யலாம்; இல்லையெனில் முழுப் பாதையைத் தட்டச்சு செய்ய வேண்டும் அல்லது அந்தக் கோப்புறையில் இருக்க வேண்டும்.

சரிபார்க்க: புதிய முனையத்தைத் திறந்து sutram --version இயக்கவும். பதிப்பு தெரிந்தால் PATH சரி. இல்லையெனில் PATH விருப்பத்துடன் நிறுவியை மீண்டும் இயக்கவும், அல்லது sutram.exe உள்ள கோப்புறையிலிருந்து இயக்கவும்.

17.7 உங்கள் முதல் விண்டோஸ் நிரல்

namaste.sm கோப்பை உருவாக்கவும்:

# எனது முதல் விண்டோஸ் நிரல்
mukhya()
    likha("வணக்கம், விண்டோஸ்!")

தொகுத்து இயக்கவும்:

sutram.exe namaste.sm namaste.exe
namaste.exe

வெளியீடு:

வணக்கம், விண்டோஸ்!

வெளியீட்டின் பெயரே இலக்கைத் தீர்மானிக்கிறது: .exe விண்டோஸ் செயலி, .bin லினக்ஸ். ஒரு தொகுப்பி, இரண்டு இலக்குகள்.

17.8 உருவான .exe-இல் என்ன உள்ளது

தொகுக்கப்பட்ட நிரல் ஒரு PE32+ பிரிவு:

[PE தலைப்புகள்][சிறிய இயக்கநேரம்][உங்கள் தொகுக்கப்பட்ட குறியீடு]

இயக்கநேரம் தொடக்கத்தில் செயல்முறை-சூழல் தொகுதியில் நடந்து அதன் ஏற்றுமதி அட்டவணையைப் படித்து kernel32-ஐக் கண்டுபிடிக்கிறது, எனவே நிரலில் இறக்குமதி அட்டவணையோ வெளிப்புறச் சார்போ இல்லை. வெளியீடு, உள்ளீடு, வெளியேறுதல் ஆகியவற்றை WriteFile, ReadFile, ExitProcess-க்கு மாற்றுகிறது. சூத்திரத்தால் உருவான .exe-ஐ இயக்க எதுவும் நிறுவ வேண்டியதில்லை.

17.9 விண்டோஸில் மொழித் தொகுப்புகள்

சூத்திரம் இரண்டு இடங்களில் தேடுகிறது: தற்போதைய கோப்புறையைப் பொறுத்து lang\<name>.lang, பின் %USERPROFILE%\.local\share\sutram\lang\. இரண்டாம் இடத்தில் வைத்தால் எந்தக் கோப்புறையிலிருந்தும் செயல்படும்.

sutram.exe --lang gujarati prog.sm out.exe

பத்து தொகுப்புகள்: பெங்காலி, குஜராத்தி, இந்தி, கன்னடம், மலையாளம், மராத்தி, ஒடியா, பஞ்சாபி, தமிழ், தெலுங்கு. குறிச்சொற்களின் தேவநாகரி எழுத்துப்பிழையும் ஏற்கப்படும்.

17.10 கட்டளைக் குறிப்பு

கட்டளைசெயல்
sutram.exe in.sm out.exeவிண்டோஸ் செயலியாகத் தொகு
sutram.exe in.sm out.binலினக்ஸ் செயலியாகத் தொகு
sutram.exe --lang gujarati in.sm out.exeமொழித் தொகுப்புடன் தொகு
sutram.exe -iஉரையாடல் ஷெல் (REPL)
sutram.exe --versionபதிப்பைக் காட்டு
out.exeதொகுக்கப்பட்ட நிரலை இயக்கு

17.11 திட்டங்களை எங்கு வைப்பது

எங்கும் வைக்கலாம். இரண்டு பழக்கங்கள் சிக்கலைத் தவிர்க்கும்: மிக ஆழமான பாதைகளைத் தவிர்க்கவும், இடைவெளி உள்ள பாதைகளை மேற்கோளில் வைக்கவும் — sutram.exe "C:\My Files\a.sm" "C:\out\a.exe". யூனிகோட் கோப்புறைப் பெயர்கள் செயல்படும்; தொகுப்பி கோப்புகளை விண்டோஸ் API மூலம் திறக்கிறது.

17.12 சிக்கல் தீர்த்தல்

அறிகுறிகாரணம்தீர்வு

இயங்குகிறது, எதையும் அச்சிடவில்லைபிரிவு வாசிப்பு-மட்டும் இருந்த பழைய கட்டமைப்புஇந்தக் கட்டமைப்பைப் பயன்படுத்தவும்

தொகுக்கப்பட்ட நிரல் இரட்டை-கிளிக்கில் எதுவும் செய்யவில்லைஇது console நிரல்; முனையம் தேவைCommand Prompt அல்லது PowerShell-இல் இயக்கவும்

17.13 மேம்படுத்தல் மற்றும் நீக்கம்

மேம்படுத்த: புதிய Sutram-Setup.exe-ஐ இயக்கவும் — அது தற்போதைய நிறுவலைக் கண்டறிந்து பாதுகாப்பாக மாற்றும். நீக்க: Settings → Apps → Installed apps → Sutram → Uninstall. நீக்கி தான் நிறுவிய கோப்புகளை மட்டும் அகற்றும்; நீங்கள் உருவாக்கியவற்றை விட்டுவிடும்.

17.14 லினக்ஸ், விண்டோஸ் அருகருகே

லினக்ஸ்விண்டோஸ்
தொகுப்பி பைனரிELF (sutram_compiler)PE (sutram.exe)
வெளியீட்டு வடிவம்ELF (.bin)PE (.exe)
நிறுவல்ஒரு-வரி ஸ்கிரிப்ட் (install.sh)வழிகாட்டி அல்லது கோப்புறை
மொழித் தொகுப்புகள்lang/, பின் $HOME/.local/share/sutram/lang/lang\, பின் %USERPROFILE%\.local\share\sutram\lang\
மொழியின் நடத்தைஒன்றே — ஒரே மூலம், ஒரே குறிச்சொல், ஒரே பொருள்

17.15 விண்டோஸில் இன்னும் வரவேண்டியவை

இப்போது செயல்படுபவை: தொகுத்தல், likha மற்றும் shabda, கணிதம், மாறிகள், yadi/anya, yavat, chakra, krama/agrim, ஆறு தொகுதிகள் வரை சார்புகள், மறுநிகழ்வு, முன்கூட்டிய திரும்புதல், தொகுதிக் குறிப்புகள், மொழித் தொகுப்புகள், பிழைச் செய்திகள்.

Windows இல் விசைப்பலகை உள்ளீடு (grahan) இப்போது வேலை செய்கிறது: உருவாக்கப்பட்ட .exe லினக்ஸ் சிஸ்டம் காலுக்குப் பதிலாக எம்பெடட் ரன்டைம் (ReadFile) வழியாகப் படிக்கிறது. அணி (mala) மற்றும் அமைப்பு (rachana) VirtualAlloc வழியாக நினைவகம் பெறுகின்றன. இன்னும் போர்ட் செய்யப்படவில்லை: நெட்வொர்க் பில்ட்-இன்கள். இன்டராக்டிவ் REPL உருவாக்கப்பட்டுள்ளது, மேலும் உண்மையான Windows மெஷினில் இதைச் சரிபார்க்க வேண்டியுள்ளது.

17.16 தத்துவம் — மாறவில்லை

தொகுப்பி ஒரே தூய-NASM மூலமாகவே இருக்கும்; C, பைதான் அல்லது இயக்கநேரச் சார்பு இல்லை; சமசுகிருதமே மொழியின் மையம், ஒவ்வொரு இந்திய மொழிக்கும் சொந்தச் சொற்கள்; உருவான நிரல்கள் சொந்த இயந்திரக் குறியீடு, ஒருபோதும் விளக்கப்படுவதில்லை; இறுதிப் பயனருக்கு எந்தக் கருவித்தொகுப்பும் தேவையில்லை. நிறுவி வெறும் பொதியிடல் — அது மொழியின் பகுதி அல்ல.

18. புதிதாக என்ன உள்ளது — தற்போதைய மொழி

இந்தப் புத்தகம் முழுமையாக எழுதப்பட்ட பிறகு இந்தப் அத்தியாயம் சேர்க்கப்பட்டது. இதில் உள்ள அனைத்தும் இன்று மொழியின் ஒரு பகுதியாகும். இவை ஒருமுறை மட்டுமே தொகுக்கப்படாமல், சரியான பதில்களுடன் சரிபார்க்கப்பட்டுள்ளன. முந்தைய அத்தியாயங்களில் இது குறிப்பிடப்படவில்லை என்றால், இந்தப் புதிய அத்தியாயமே தற்போதைய நிலையைக் குறிக்கும்.

Floating-point எண்கள் — dasham

ஒரு variable 64-bit IEEE-754 floating-point எண்ணை வைத்திருக்கலாம். இதை dasham மூலம் அறிவிக்கவும்; தசமப் புள்ளி (decimal point) கொண்ட ஒரு literal தானாகவே float ஆகிவிடும்.

Floats, integers உடன் கலக்கப்படும் (integer promote செய்யப்படும்), நான்கு arithmetic operators மற்றும் ஆறு comparisons-ஐ ஆதரிக்கும். மேலும், ஆறு தசம இடங்களுடன் print ஆகும். Functions ஒரு float-ஐ return செய்ய முடியும் — அவை return செய்யும் மதிப்பை வைத்து compiler அதைப் புரிந்துகொள்ளும்.

வளரக்கூடிய arrays — kosh

ஒரு சாதாரண mala-இன் அளவு நிலையானது. ஆனால் ஒரு kosh வளரக்கூடியது: இது சிறிய அளவிலிருந்து தொடங்கி, தேவைக்கேற்ப இரட்டிப்பாகும்.

Capacity என்பது நீளம் (length) அல்ல. 4 capacity கொண்ட kosh-இல் capacity 4 ஆகவும், length 0 ஆகவும் இருக்கும். எனவே, ஏதாவது push செய்யப்படும் வரை index 0 out of bounds ஆக இருக்கும். இது ஆரம்பத்தில் சிலருக்குச் சிரமமாக இருக்கலாம்; ஆனால் இது திட்டமிட்டுச் செய்யப்பட்டது. இதுவே indexing-ஐ பாதுகாப்பானதாக்குகிறது.

Typed arrays — kosh dasham

Floats-ஐ வைத்திருக்க kosh-ஐ அறிவிக்கலாம். அதில் push செய்யப்படும் integer மதிப்புகள் promote செய்யப்படும், மேலும் அதன் elements எல்லா இடங்களிலும் floats ஆக செயல்படும்.

Typed function parameters

ஒரு function-க்கு ஒரு குறிப்பிட்ட வகையான argument தேவைப்படலாம், compiler அதைச் சரிபார்க்கும்.

Typed float mala ஒரு pointer ஆக அனுப்பப்படுகிறது, எனவே indexed writes caller-க்குத் தெரியும் — ஒரு function உங்களுக்காக ஒரு mala-ஐ நிரப்ப முடியும். ஆனால் அதை வளர்க்க (growing) அனுமதி இல்லை: ஒரு parameter-இல் kosh_push-ஐ அழைப்பது நிராகரிக்கப்படும். ஏனெனில் pointer by value ஆக அனுப்பப்படுகிறது, caller-க்கு ஒரு பழைய pointer மட்டுமே கிடைக்கும். இது ஒரு பாதுகாப்பு அம்சம், விடுபட்ட feature அல்ல.

Standard library

Compiler-உடன் பதினைந்து modules வருகின்றன. yoj மூலம் ஒன்றைப் import செய்யவும். அவை arithmetic மற்றும் number theory; sorting மற்றும் text; Pingala-வின் prosody; Aryabhata மற்றும் Bhaskara-வின் கணிதம்; pi, sine, cosine மற்றும் vargit root-க்கான Kerala school-இன் series; statistics; numerical calculus — integration, derivatives மற்றும் polynomial roots; matrices மற்றும் determinants-உடன் linear algebra; மற்றும் patra reading மற்றும் writing ஆகியவற்றை உள்ளடக்கியது.

Try it: heritage modules உண்மையான கணிதத்தைக் கணக்கிடுகின்றன — 61-இன் chakravala, x squared minus 61 y squared equals 1 என்பதற்கான மிகச்சிறிய தீர்வை வழங்குகிறது, அது x = 1766319049, y = 226153980. இது 7-ஆம் நூற்றாண்டு முறை, சரியான பதிலுடன் சரிபார்க்கப்பட்டது.

Sutram IDE

மொழியுடன் install செய்யப்படுகிறது. இது ஒரு native program — Python இல்லை, interpreter இல்லை. line numbers மற்றும் syntax highlighting கொண்ட code editor இதில் உள்ளது; நீங்கள் எழுதியதை compile செய்து run செய்ய Ctrl-R; example programs-ஐ ஒவ்வொன்றாகப் பார்க்க Ctrl-E; interactive shell-க்கு Ctrl-T, இதில் நீங்கள் ஒரு statement-ஐ type செய்து Enter-ஐ அழுத்தி அது run ஆவதைப் பார்க்கலாம். session முந்தைய வரிகளை நினைவில் வைத்துக்கொள்வதால், நீங்கள் படிப்படியாக ஒரு program-ஐ உருவாக்கலாம்; save செய்ய Ctrl-S, load செய்ய Ctrl-L, quit செய்ய Ctrl-Q.

Windows-இல் IDE இன்னும் கிடைக்கவில்லை; அதற்குப் பதிலாக interactive shell-ஐப் பயன்படுத்தவும்.

வேகம் — கூறப்படுவது அல்ல, அளவிடப்படுவது

Compiler variable மதிப்புகளை memory-இல் அல்லாமல் processor registers-இல் வைத்திருக்கிறது. ஒரு representative numerical program-இல், சமீபத்திய சோதனைகளில் இது சுமார் 1.2 மடங்கு வேகத்தை அதிகரித்தது. ஒரு tight integer loop-இல் உருவாக்கப்பட்ட code 13 instructions-லிருந்து 5-ஆகக் குறைந்தது — அளவிடப்பட்ட 4.9 மடங்கு. இந்தப் பகுதியில் உள்ள ஒவ்வொரு கூற்றும் ஒரே இயந்திரத்தில் முன்னும் பின்னும் அளவிடப்பட்டதே தவிர, கணிக்கப்படவில்லை.

        i = i + 1
    }
