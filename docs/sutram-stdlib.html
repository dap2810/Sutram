Every module is pulled in with ayojan <name> and inlined into your program at compile time — no runtime, the code becomes part of your binary. No module defines a function that another module also defines, so any set can be imported together.

sankhyiki — सांख्यिकी (statistics)

The first module built on typed kosh dasham parameters: every function takes a float array and only reads it. Variance and standard deviation are the population forms (divide by n).

FunctionMeaning

Verified against the textbook dataset [2,4,4,4,5,5,7,9]: mean 5, variance 4, stddev 2, range 7 — every value exact. Empty arrays return 0 rather than dividing by zero.

kalana — कलन (numerical calculus)

Built on typed kosh dasham parameters and the float fast paths. Sutram has no first-class functions, so anything that would take a callback takes either samples (integration, differentiation) or polynomial coefficients (root finding). Coefficients are ascending: c[0] + c[1]x + c[2]x².

FunctionMeaning
trapezoid(xs, ys)trapezoidal integration over samples
simpson(xs, ys)Simpson's 1/3 rule (falls back to trapezoid if too few points)
slope(xs, ys, i)first derivative at sample i (central, one-sided at the ends)
slope2(xs, ys, i)second derivative at an interior sample
bahu_ganana(c, x)polynomial evaluation by Horner's method
bahu_mula(c, lo, hi, ok)bisection root of a polynomial on [lo,hi]

Verified against known answers: ∫₀¹x²dx = 0.335000 (trapezoid) and 0.333333 (Simpson, exact for a quadratic); d/dx(x²) = 1.0 at x=0.5 and second derivative 2.0; the root of x²−2 is 1.414214 = √2. Contract: bahu_mula's ok array must already contain one element (kosh_push(ok, 0.0) first) — a kosh's capacity is not its length.

samanvaya — समन्वय (linear algebra)

Sutram has no 2-D array type, so a matrix is a flat kosh dasham of m×n elements in row-major order, with dimensions passed explicitly: A[i][j] == a[i*n + j].
