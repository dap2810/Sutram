The rule

Two tests, both must pass: easy to remember and easy to type — short, no diacritics, no heavy clusters. Accuracy never wins over usability. If a word is correct but hard to type, it loses.

The aim: someone who reads and writes an Indian language but knows no English at all must be able to learn and use this language. Sanskrit is canonical; the 11 packs render each word into Hindi, Marathi, Gujarati, Bengali, Punjabi, Odia, Tamil, Telugu, Kannada and Malayalam.
