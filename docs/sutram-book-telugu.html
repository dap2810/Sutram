సూత్రమ్ పుస్తకం

ముందుమాట. సూత్రం (Sutram) అనేది ఒక ప్రోగ్రామింగ్ లాంగ్వేజ్. దీని కీవర్డ్స్ సంస్కృతంలో ఉంటాయి. ఇది కేవలం అలంకారం కోసం కాదు, ఒక డిజైన్ కమిట్‌మెంట్. దీని పేరు 'సూత్రం' అంటే 'సూత్రాలు' అని అర్థం. ఇది ప్రపంచంలోనే మొట్టమొదటి ఫార్మల్ గ్రామర్ అయిన పాణిని రాసిన అష్టాధ్యాయిలోని సంక్షిప్త నియమ-రూపాన్ని సూచిస్తుంది. దీని స్టాండర్డ్ లైబ్రరీ భారతీయ గణిత సంప్రదాయాన్ని నేరుగా అమలు చేస్తుంది. ఇందులో పింగళుని బైనరీ, మేరు-ప్రస్తార, ఆర్యభటుని కుట్టక, భాస్కరుని చక్రవాళ ఉన్నాయి. అంతేకాకుండా, దీని కంపైలర్ దానంతట అదే పనిచేస్తుంది. మీరు ఎలాంటి రన్‌టైమ్ లేదా టూల్‌చైన్ అవసరం లేకుండానే, ఒకే ఒక చేతితో రాసిన అసెంబ్లీ ఫైల్ నేటివ్ మెషిన్ కోడ్‌ను ఉత్పత్తి చేస్తుంది. ఈ పుస్తకం ఈ భాషను మొదటి నుండి నేర్పుతుంది. ఇందులోని ప్రతి ఉదాహరణ కంపైల్ అయ్యి రన్ అయ్యే నిజమైన కోడ్. అలాగే, ఈ భాష గురించి చేసిన ప్రతి వాదనను మీరు స్వయంగా సరిచూసుకోవచ్చు.
💡 వాడే విధానం: కుంకుమ చుక్కలున్న పదంపై మౌస్ తిప్పండి — దాని సంస్కృత పదం, English అర్థం వెంటనే కనిపిస్తాయి. (ముద్రిత పేజీల కోసం ప్రతి అధ్యాయం చివర పట్టిక ఉంది.)

సంస్కృత కీలకపదం‌లు. నేటివ్ మెషిన్ కోడ్. ప్రతి భాషను కలిపే ఒక దారం.

1. సూత్రమ్ అంటే ఏమిటి? (What is Sutram?)

సూత్రమ్ అంటే "దారం" — అన్నింటినీ కలిపే దారం. సూత్రమ్ ఒక ప్రోగ్రామింగ్ భాష: దీని కీలకపదంలు సంస్కృతం నుండి వచ్చాయి, దీని సంకలని స్వచ్ఛమైన అసెంబ్లీలో రాయబడింది, ఇది నేరుగా x86-64 మెషిన్ కోడ్‌గా మారుతుంది. ఇంటర్‌ప్రెటర్ లేదు, వర్చువల్ మెషిన్ లేదు, రన్‌టైమ్ లైబ్రరీ లేదు.

ఎందుకు నేర్చుకోవాలి?

1. పైథాన్ సరళత, C వేగం. మీరు శుభ్రమైన సంస్కృత కీలకపదం‌లతో చదవగలిగే కోడ్ రాస్తారు; సంకలని చిన్న నేటివ్ బైనరీని తయారు చేస్తుంది — చేతితో రాసిన అసెంబ్లీ వేగంతో నడుస్తుంది.

2. అంతా కనిపిస్తుంది. సంకలని ఒక చదవగలిగే అసెంబ్లీ ఫైలు (~9000 లైన్లు) — నిజమైన సంకలని ఎలా పనిచేస్తుందో చూడవచ్చు: లెక్సర్ → పార్సర్ → కోడ్ జెనరేటర్ → ELF రైటర్.

3. మీ భాష, మీ మాటలు. భాషా సంకులం‌తో ప్రతి కీలకపదం‌ను తెలుగు, హిందీ, బెంగాలీ, తమిళం మొదలైన పది భారతీయ భాషల్లో రాయవచ్చు. సంస్కృత కీలకపదం‌లు మూలం — అన్ని భాషలను కలిపే దారం.

కావాల్సింది: Linux x86-64 సిస్టమ్ (లేదా Windows‌పై WSL). వేరే డిపెండెన్సీ లేదు — C సంకలని కూడా అవసరం లేదు.

2. మీ మొదటి కార్యక్రమం (Your first program)

ప్రతి సూత్రమ్ కార్యక్రమం mukhya()‌తో మొదలవుతుంది — నడిచే "ముఖ్య" ధార. సెమీకోలన్లు ఐచ్ఛికం; ఒక స్టేట్‌మెంట్‌కు బ్రేస్‌లు కూడా ఐచ్ఛికం; కామెంట్‌లు //‌తో మొదలవుతాయి.

mukhya()
    likha("Namaste, Sutram!\n")

దీన్ని namaste.sm అనే పేరుతో సేవ్ చేసి, కంపైల్ చేసి రన్ చేయండి:

$ sutram namaste.sm namaste.bin
Siddh: 97 byte sankalit
$ ./namaste.bin
Namaste, Sutram!
సంకలని పూర్తి నడిచే ELF బైనరీని తయారు చేస్తుంది — ఈ కార్యక్రమం‌కు కేవలం 90 బైట్‌లు. అంతే మొత్తం కార్యక్రమం: ప్రోలాగ్, మీ likha కాల్, exit syscall.

3. చరరాశులు మరియు స్థిరాంకాలు (Variables and constants)

vitti ("ఒక స్థితి") తో చరరాశి ప్రకటించండి. పూర్ణాంకాలకు anka. స్థిరాంకం‌లకు sutra:

mukhya()
    vitti x = 10
    x = x + 5
    likha(x)        // 15
    sutra pi = 314
    likha(pi / 100)  // 3
    likha("\n")

మొదటి ఐదు చరరాశులు రిజిస్టర్లలో (rbx, r12–r15) ఉంటాయి — సంకలని వాటిని స్వయంగా కేటాయిస్తుంది. మిగిలినవి స్టాక్‌కు వెళ్తాయి.

4. సంకారకాలు మరియు ప్రాధాన్యత (Operators and precedence)

సూత్రమ్‌లో మీరు ఆశించే పూర్తి సంకారకం సెట్ ఉంది, ప్రామాణిక గణిత నియమాలతో:

OperatorMeaningExample
+ - * / %arithmetic, modulo17 % 5 → 2
== != < > <= >=comparisonx >= 18
&& ||logical and / ora > 0 && b > 5
& | ^bitwise2 & 12 → 0
( ... )grouping(3 + 4) * 2 → 14

బ్రాకెట్‌లు ప్రాధాన్యతను మార్చుతాయి — గణితంలో లాగే:

mukhya()
    vitti a = 3
    vitti b = 4
    likha((a + b) * 2)   // 14
    likha("\n")
    likha(17 % 5)         // 2
    likha("\n")
    likha(2 & 12)         // 0  (bitwise AND)
    likha("\n")
ప్రాధాన్యత (తక్కువ నుండి ఎక్కువ): || → && → పోలికలు → + - & | ^ → * / %. సందేహం ఉంటే బ్రాకెట్‌లు వాడండి — పనితీరుపై ఖర్చు లేదు.

5. నిర్ణయాలు: yadi / anya (Decisions (if / else))

yadi (ఒకవేళ) షరతు నిజమైనప్పుడు బ్లాక్‌ను నడుపుతుంది; anya (లేకపోతే) లేకుంటే. షరతుల గొలుసు కోసం మళ్ళీ మళ్ళీ yadi రాయండి:

mukhya()
    vitti mulya = 0
    yadi (mulya > 0) {
        likha("Positive\n")
    } yadi (mulya < 0) {
        likha("Negative\n")
    } anya {
        likha("Zero\n")
    }

ఒక విలువను చాలా సందర్భాలతో పోల్చడానికి guna (switch) మరియు bhavana (case) వాడండి:

mukhya()
    vitti divasa = 3
    guna (divasa) {
        bhavana 1: { likha("Somvaar\n") }
        bhavana 2: { likha("Mangalvaar\n") }
        bhavana 3: { likha("Budhvaar\n") }
        anya: { likha("Anyo divaah\n") }
    }

6. పునరావృతాలు: chakra, yavat, krama, agrim (Loops)

chakra (పునరావృతం) లెక్కించే పునరావృతం — "i = a నుండి b వరకు":

mukhya()
    chakra i = 1 tak 5 {
        likha(i)
        likha(" ")   // 1 2 3 4 5
    }
    likha("\n")

yavat (ఎంతవరకు) while-పునరావృతం. krama పునరావృతం‌ను ఆపుతుంది; agrim తర్వాతి రౌండ్‌కు వెళ్తుంది:

mukhya()
    vitti yogam = 0
    chakra i = 1 tak 100 {
        yadi (i > 10) { krama }
        yadi (i % 2 == 0) { agrim }
        yogam = yogam + i
    }
    likha(yogam)     // 25
    likha("\n")
ఈ కార్యక్రమం 1 నుండి 10 వరకు బేసి సంఖ్యల మొత్తం: i > 10 అయినప్పుడు krama పునరావృతం ఆపుతుంది; i జత సంఖ్య అయినప్పుడు agrim దాన్ని వదిలేస్తుంది. సమాధానం: 25.

7. ప్రమేయాలు: prakriya (Functions)

prakriya (ప్రక్రియ) ఒక పేరున్న బ్లాక్ — ఆరు ఆర్గ్యుమెంట్‌ల వరకు తీసుకుంటుంది, prati‌తో విలువను తిరిగి ఇస్తుంది:

prakriya vishalya(mulya)
    prati mulya * mulya

mukhya()
    vitti phalam = vishalya(7)
    likha(phalam)     // 49
    likha("\n")

ప్రమేయాలు తమను తాము కాల్ చేయగలవు — రికర్షన్ సూటిగా పనిచేస్తుంది:

prakriya fib(n) {
    yadi (n < 2) { prati n }
    prati fib(n - 1) + fib(n - 2)
}

mukhya()
    likha(fib(10))     // 55
    likha("\n")

8. వ్యూహాలు: mala (Arrays)

పంక్తి అంటే "వరుస" — వస్తువుల ఒక వరుస. mala‌తో వ్యూహం ప్రకటించండి: mala tarika[5] అంటే ఐదు 64-బిట్ స్లాట్‌లు:

mukhya()
    mala tarika[5]
    chakra i = 0 tak 5 {
        tarika[i] = i * i
    }
    likha(tarika[4])     // 16
    likha("\n")

arr[i] పాయింటర్ ద్వారా నేరుగా చదువుతుంది-రాస్తుంది — ఒక మెషిన్ ఇన్‌స్ట్రక్షన్, C వేగం.

9. enum మరియు స్థిరాంకాలు: ganana, sutra (Enums and constants)

ganana (సృష్టి) పేరున్న పూర్ణాంక స్థిరాంకం‌లను తయారు చేస్తుంది — ఒక enum:

mukhya()
    ganana LAAL = 1
    ganana HARA = 2
    ganana NEELA = 3
    vitti mera_ranga = HARA
    guna (mera_ranga) {
        bhavana 1: { likha("Red\n") }
        bhavana 2: { likha("Green\n") }
        bhavana 3: { likha("Blue\n") }
    }

10. సూత్రమ్ కవచం (REPL) (The Sutram shell (REPL))

సంస్కరణ 1.0‌లో ఒక ఇంటరాక్టివ్ కవచం వచ్చింది — పైథాన్ IDLE లాగా. ఇలా ప్రారంభించండి: sutram -i:

$ sutram -i

Sutram kathan likho aur Enter dabao. Turant chalega.
Aadesh: sahayata (sahay) | nirgat (nikas) | sarvam (dekho)

sutra> vitti x = 21
Siddh: 54 byte sankalit
sutra> likha(x / 3)
Siddh: 201 byte sankalit
7
sutra> nirgat

మీరు టైప్ చేసిన ప్రతి లైన్ పెరుగుతున్న సెషన్ కార్యక్రమం‌లో చేరుతుంది, వెంటనే కంపైల్ అవుతుంది, నడుస్తుంది. చరరాశులు లైన్‌ల మధ్య నిలిచి ఉంటాయి.

కవచం కమాండ్‌లు: sahayata (సహాయం) · sarvam (పూర్తి సెషన్ చూపించు) · nirgat (నిష్క్రమణ)

15. సాంకేతిక పదకోశం (Technical Glossary) (Technical glossary)

ఈ పుస్తకంలో వాడిన సాంకేతిక పదాల ప్రామాణిక తెలుగు రూపాలు — మరియు వాటి కారణాలు:

Program → కార్యక్రమం — కార్యం (పని) + క్రమం (వరుస) = క్రమబద్ధమైన పనుల ప్రణాళిక. "ప్రోగ్రామ్"కు ప్రామాణిక తెలుగు పదం.

Compiler → సంకలని — సంకలనం (ఒకచోట చేర్చడం) చేసేది: మూల కోడ్‌ను యంత్ర కోడ్‌గా మార్చే అనువాదకుడు.

Computer → గణన యంత్రం — గణన (లెక్క) చేసే యంత్రం. తెలుగు పాఠ్యపుస్తకాల్లో "కంప్యూటర్" అనే లిప్యంతరీకరణ కూడా వాడుకలో ఉంది; స్వచ్ఛమైన తెలుగు మాట గణన యంత్రం.

Keyword → కీలకపదం — కీలకమైన (ముఖ్యమైన) పదం; భాషకు ప్రత్యేకంగా కేటాయించిన పదాలు, ఉదా: mukhya, vitti.

Variable → చరరాశి — విలువ మారగల రాశి. గణిత పాఠ్యపుస్తకాల్లో x, y చరరాశులకు ప్రామాణిక పదం; సంక్షిప్తంగా "చరం" అని కూడా అంటారు.

Constant → స్థిరరాశి — స్థిరమైన (మారని) విలువ గల రాశి; "అచరం" అనే పదం కూడా వాడుకలో ఉంది.

Function → ప్రమేయం — ఇన్‌పుట్ నుండి అవుట్‌పుట్‌కు నియమం; గణిత శాస్త్రం నుండి వచ్చిన ప్రామాణిక పదం.

Loop → పునరావృత్తి — పునః (మళ్ళీ) + ఆవృత్తి (చుట్టం): బంధుత్వంగా మళ్ళీ మళ్ళీ నడిచే కోడ్; "పునరావృతం"కు ప్రామాణిక తెలుగు పదం.

Array → వరుస / శ్రేణి — వరుసగా అమర్చిన విలువల సమూహం. సూత్రమ్‌లో దీనికి mala (వరుస) అనే కీలకపదం ఉంది.

Memory → జ్ఞాపకశక్తి — సమాచారాన్ని దాచి ఉంచే చోటు; "మెమరీ" అనే మాట అర్థం చెప్పదు, ఉచ్చరణ మాత్రమే.

Machine Code → యంత్ర కోడ్ — CPU నేరుగా నడుపుతుంది అని రెండు-ఆధార (binary) కోడ్. సూత్రమ్ నేరుగా దీనిపైనే సంకలనం అవుతుంది.

String → తీగ — అక్షరాల పునశ్చరమ్ (గొలుసు). సంస్కృతంలో "సూత్రం" అంటే దారం/తీగే — అందుకే భాషకు సూత్రమ్ అని పేరు!

Error → దోషం — కార్యక్రమంలో తప్పు; సంకలని దాన్ని వరుస సంఖ్యతో చూపిస్తుంది. "తప్పు" అనే మాట కూడా వాడుకలో ఉంది.

Debugging → దోష సవరణ — దోషాన్ని (bug) కనుగొని సరిచేసే ప్రక్రియ.

Language → భాష — ప్రోగ్రామింగ్ భాష: మనిషి కంప్యూటరుకు ఆజ్ఞలు ఇచ్చే విధానం.

17. విండోస్‌పై స్థాపన — పూర్తి మార్గదర్శిని

సూత్రమ్ విండోస్‌ను లినక్స్‌లాగే ప్రథమ శ్రేణి లక్ష్యంగా పరిగణిస్తుంది. మునుపటి అధ్యాయాలన్నీ అదే విధంగా పనిచేస్తాయి; స్థాపన దశ మాత్రమే మారుతుంది, దాన్నే ఈ అధ్యాయం పూర్తిగా వివరిస్తుంది.

17.1 మీకు ఏమి లభిస్తుంది

  • sutram.exe — స్థానిక Win64 కార్యక్రమంగా (PE32+) ఉన్న సంకలని.
  • సంకలనం చేసిన కార్యక్రమాలు నిజమైన విండోస్ ఎగ్జిక్యూటబుల్స్, స్క్రిప్టులు కావు.
  • WSL, లినక్స్ VM, పైథాన్ లేదా C రన్‌టైమ్ అవసరం లేదు.
  • ఒకే సంకలని మూలం నుండి విండోస్, లినక్స్ రెండూ వస్తాయి, కాబట్టి భాష ప్రవర్తన రెండింటిలో ఒకటే.

17.2 అవసరాలు

  • విండోస్ 10 లేదా 11, 64-బిట్.
  • సాధారణ వినియోగానికి మరేమీ అవసరం లేదు. సంకలనిని మీరే నిర్మిస్తే మాత్రమే NASM కావాలి.

17.3 స్థాపన — పద్ధతి అ: విజార్డ్ (సిఫార్సు)

  1. Sutram-Setup.exe పొందండి.
  2. దానిపై డబుల్-క్లిక్ చేయండి. కొత్త కార్యక్రమానికి విండోస్ SmartScreen హెచ్చరిక చూపవచ్చు: More info → Run anyway ఎంచుకోండి.
  3. విజార్డ్ గమ్యస్థాన ఫోల్డర్ అడుగుతుంది. డిఫాల్ట్ C:\Program Files\Sutram. దాన్ని అంగీకరించండి, లేదా Browse తో మీ ఫోల్డర్ ఎంచుకోండి.
  4. ఏ ఫోల్డర్ నుండైనా sutram టైప్ చేయాలంటే “Add Sutram to PATH” ఎంచుకోండి. ఇది సిఫార్సు చేయబడింది.
  5. కావాలంటే Start Menu నమోదు, Desktop షార్ట్‌కట్ ఎంచుకోండి.
  6. Install నొక్కండి. పూర్తయ్యాక మూసేయండి.

తర్వాత సూత్రమ్ Apps & Features లో నమోదవుతుంది, కాబట్టి Settings నుండి మరమ్మతు, నవీకరణ లేదా తొలగింపు చేయవచ్చు.

17.4 స్థాపన — పద్ధతి ఆ: పోర్టబుల్ ఫోల్డర్

  1. sutram-windows-native.zip ను ఎక్కడైనా తెరవండి, ఉదా. C:\Sutram.
  2. ఫోల్డర్‌ను కలిసి ఉంచండి — భాషా ప్యాక్‌లు sutram.exe పక్కన lang\ లో ఉంటాయి.
  3. అదే ఫోల్డర్‌లో టెర్మినల్ తెరవండి (Shift + కుడి-క్లిక్ → Open in Terminal).
  4. కావాలంటే install.bat ఒకసారి నడపండి — అది ఫోల్డర్‌ను PATH లో చేరుస్తుంది.

17.5 స్థాపన — పద్ధతి ఇ: మూలం నుండి నిర్మాణం

డెవలపర్‌లకు. NASM మరియు PE-సమర్థ లింకర్ (GNU ld, MSVC, lld-link) కావాలి:

nasm -f win64 -dWINDOWS -I. src\sutram_compiler.asm -o sutram.obj
ld -mi386pep --entry=_start -o sutram.exe sutram.obj

విజార్డ్ ఇన్‌స్టాలర్ కూడా నిర్మించాలంటే MinGW GCC మరియు PowerShell కావాలి; స్క్రిప్టులు windows\ లో ఉన్నాయి (BUILD-WINDOWS-SETUP.cmd).

17.6 PATH ను అర్థం చేసుకోవడం

PATH అంటే మీరు కమాండ్ టైప్ చేసినప్పుడు విండోస్ వెతికే ఫోల్డర్ల జాబితా. సూత్రమ్ ఫోల్డర్ PATH లో ఉంటే ఎక్కడి నుండైనా sutram టైప్ చేయవచ్చు; లేకపోతే పూర్తి మార్గం టైప్ చేయాలి లేదా ఆ ఫోల్డర్‌లో ఉండాలి.

తనిఖీ: కొత్త టెర్మినల్ తెరిచి sutram --version నడపండి. వెర్షన్ కనిపిస్తే PATH సరైనది. లేకపోతే PATH ఎంపికతో ఇన్‌స్టాలర్ మళ్లీ నడపండి, లేదా sutram.exe ఉన్న ఫోల్డర్ నుండి నడపండి.

17.8 ఉత్పన్నమైన .exe లో ఏమి ఉంటుంది

సంకలనం చేసిన కార్యక్రమం ఒక PE32+ సెక్షన్:

[PE శీర్షికలు][చిన్న రన్‌టైమ్][మీ సంకలిత కోడ్]

రన్‌టైమ్ ప్రారంభంలో ప్రక్రియ-పర్యావరణ బ్లాక్‌లో నడిచి దాని ఎగుమతి పట్టికను చదివి kernel32 ను కనుగొంటుంది, కాబట్టి కార్యక్రమంలో దిగుమతి పట్టిక లేదా బాహ్య ఆధారం ఉండదు. అవుట్‌పుట్, ఇన్‌పుట్, నిష్క్రమణలను WriteFile, ReadFile, ExitProcess కు మళ్లిస్తుంది. సూత్రమ్‌తో చేసిన .exe నడపడానికి ఏమీ ఇన్‌స్టాల్ చేయాల్సిన అవసరం లేదు.

17.9 విండోస్‌పై భాషా ప్యాక్‌లు

సూత్రమ్ రెండు చోట్ల వెతుకుతుంది: ప్రస్తుత ఫోల్డర్‌కు సాపేక్షంగా lang\<name>.lang, తర్వాత %USERPROFILE%\.local\share\sutram\lang\. రెండో చోట ఉంచితే ఏ ఫోల్డర్ నుండైనా పనిచేస్తాయి.

sutram.exe --lang gujarati prog.sm out.exe

పది ప్యాక్‌లు: బెంగాలీ, గుజరాతీ, హిందీ, కన్నడ, మలయాళం, మరాఠీ, ఒడియా, పంజాబీ, తమిళం, తెలుగు. కీలకపదాల దేవనాగరి వర్ణక్రమం కూడా ఆమోదించబడుతుంది.

ఇప్పుడు పనిచేస్తున్నవి: సంకలనం, likha మరియు shabda, గణితం, చరరాశులు, yadi/anya, yavat, chakra, krama/agrim, మూడు ఆర్గ్యుమెంట్ల వరకు ప్రమేయాలు, పునరావృత్తి, ముందస్తు ప్రత్యాగమనం, బ్లాక్ వ్యాఖ్యలు, భాషా ప్యాక్‌లు, దోష సందేశాలు.

Windows లో కీబోర్డ్ ఇన్‌పుట్ (grahan) ఇప్పుడు పనిచేస్తుంది: తయారైన .exe Linux సిస్టమ్ కాల్‌కు బదులుగా ఎంబెడెడ్ రన్‌టైమ్ (ReadFile) ద్వారా చదువుతుంది. వ్యూహం (mala) మరియు నిర్మాణం (rachana) VirtualAlloc ద్వారా మెమరీ తీసుకుంటాయి. ఇంకా పోర్ట్ కాలేదు: నెట్‌వర్క్ బిల్ట్‌ఇన్స్. ఇంటరాక్టివ్ REPL పూర్తయింది, దీన్ని ఒక నిజమైన Windows మెషీన్‌లో చెక్ చేయాల్సి ఉంది.

17.16 తత్వం — మారలేదు

సంకలని ఒకే శుద్ధ-NASM మూలంగా ఉంటుంది; C, పైథాన్ లేదా రన్‌టైమ్ ఆధారం లేదు; సంస్కృతమే భాష కేంద్రం, ప్రతి భారతీయ భాషకు సొంత పదాలు; ఉత్పన్నమైన కార్యక్రమాలు స్థానిక యంత్ర కోడ్, ఎప్పుడూ వ్యాఖ్యానించబడవు; తుది వినియోగదారుకు ఏ టూల్‌చెయిన్ అవసరం లేదు. ఇన్‌స్టాలర్ కేవలం ప్యాకేజింగ్ — అది భాషలో భాగం కాదు.

18. కొత్తగా ఏముంది — ప్రస్తుత భాష

ఈ పుస్తకంలోని మిగతా భాగం తర్వాత ఈ అధ్యాయాన్ని చేర్చారు. ఇందులోని ప్రతిదీ ఈరోజు భాషలో భాగమే. ఇది కేవలం ఒక్కసారి కంపైల్ చేయడమే కాకుండా, సరైన సమాధానాలతో సరిచూడబడింది. మునుపటి అధ్యాయంలో ఇక్కడ చెప్పిన విషయం ప్రస్తావించకపోతే, ఈ అధ్యాయం మరింత తాజాది.

Floating-point numbers — dasham

ఒక వేరియబుల్ 64-bit IEEE-754 floating-point నంబర్‌ను కలిగి ఉండవచ్చు. దీన్ని dasham తో డిక్లేర్ చేయండి; డెసిమల్ పాయింట్ ఉన్న లిటరల్ ఆటోమేటిక్‌గా ఫ్లోట్ అవుతుంది.

ఫ్లోట్స్ ఇంటిజర్లతో కలుస్తాయి (ఇంటిజర్ ప్రమోట్ అవుతుంది), నాలుగు అంకగణిత ఆపరేటర్లకు మరియు ఆరు పోలికలకు సపోర్ట్ చేస్తాయి, మరియు ఆరు డెసిమల్ ప్లేసెస్‌తో ప్రింట్ అవుతాయి. ఫంక్షన్స్ ఫ్లోట్‌ను రిటర్న్ చేయగలవు — అవి ఏమి రిటర్న్ చేస్తాయో బట్టి కంపైలర్ దాన్ని అర్థం చేసుకుంటుంది.

Growable arrays — kosh

సాధారణ అర్రే సైజు ఫిక్స్‌డ్‌గా ఉంటుంది. kosh పెరుగుతుంది: ఇది చిన్న కెపాసిటీతో మొదలవుతుంది మరియు అవసరమైనప్పుడు రెట్టింపు అవుతుంది.

కెపాసిటీ అంటే పొడవు కాదు. 4 కెపాసిటీతో డిక్లేర్ చేసిన kosh కు కెపాసిటీ 4 ఉంటుంది కానీ పొడవు 0, కాబట్టి ఏదైనా పుష్ చేసే వరకు ఇండెక్స్ 0 అవుట్ ఆఫ్ బౌండ్స్ అవుతుంది. ఇది మొదట్లో జనాలను కన్ఫ్యూజ్ చేస్తుంది; ఇది ఉద్దేశపూర్వకంగానే, మరియు ఇది ఇండెక్సింగ్‌ను సురక్షితంగా చేస్తుంది.

Typed arrays — kosh dasham

ఫ్లోట్స్‌ను కలిగి ఉండేలా kosh ను డిక్లేర్ చేయవచ్చు. అందులో పుష్ చేసిన ఇంటిజర్ వాల్యూలు ప్రమోట్ అవుతాయి, మరియు దాని ఎలిమెంట్స్ అంతటా ఫ్లోట్స్‌లా ప్రవర్తిస్తాయి.

Typed function parameters

ఒక ఫంక్షన్‌కు ఒక నిర్దిష్ట రకమైన ఆర్గ్యుమెంట్ అవసరం కావచ్చు, మరియు కంపైలర్ దాన్ని చెక్ చేస్తుంది.

టైప్డ్ ఫ్లోట్ అర్రే పాయింటర్‌గా పాస్ చేయబడుతుంది, కాబట్టి ఇండెక్స్డ్ రైట్స్ కాలర్‌కు కనిపిస్తాయి — ఒక ఫంక్షన్ మీ కోసం అర్రేను నింపగలదు. కానీ దాన్ని పెంచడానికి అనుమతించబడదు: పారామీటర్‌పై kosh_push ని కాల్ చేయడం నేమ్డ్ ఎర్రర్‌తో తిరస్కరించబడుతుంది, ఎందుకంటే పాయింటర్ బై వాల్యూగా పాస్ చేయబడుతుంది మరియు కాలర్ పాత పాయింటర్‌తో మిగిలిపోతాడు. ఇది ఉద్దేశపూర్వకమైన భద్రతా సరిహద్దు, మిస్సయిన ఫీచర్ కాదు.

The standard library

కంపైలర్‌తో పాటు పదిహేను మాడ్యూల్స్ వస్తాయి. yoj తో ఒకదాన్ని ఇంపోర్ట్ చేయండి. అవి అంకగణితం మరియు నంబర్ థియరీ; సార్టింగ్ మరియు టెక్స్ట్; Pingala's prosody; Aryabhata మరియు Bhaskara ల గణితం; pi, sine, cosine మరియు vargit root కోసం Kerala school's series; గణాంకాలు; న్యూమరికల్ క్యాలిక్యులస్ — integration, derivatives మరియు polynomial roots; matrices మరియు determinants తో linear algebra; మరియు ఫైల్ రీడింగ్ మరియు రైటింగ్‌ను కవర్ చేస్తాయి.

Try it: హెరిటేజ్ మాడ్యూల్స్ నిజమైన గణితాన్ని లెక్కిస్తాయి — 61 యొక్క chakravala x squared minus 61 y squared equals 1 కు అతిచిన్న పరిష్కారాన్ని రిటర్న్ చేస్తుంది, అది x = 1766319049, y = 226153980. ఇది 7వ శతాబ్దపు పద్ధతి, సరైన సమాధానంతో సరిచూడబడింది.

The Sutram IDE

భాషతో పాటు ఇన్‌స్టాల్ అవుతుంది. లైన్ నంబర్లు మరియు సింటాక్స్ హైలైటింగ్‌తో కూడిన కోడ్ ఎడిటర్ ఉన్న ఒకే ఒక నేటివ్ ప్రోగ్రామ్ — Python లేదు, ఇంటర్‌ప్రెటర్ లేదు — మీరు రాసిన దాన్ని కంపైల్ చేసి రన్ చేయడానికి Ctrl-R, అవుట్‌పుట్ కింద చూపబడుతుంది; ఉదాహరణ ప్రోగ్రామ్‌లను ఒక్కొక్కటిగా బ్రౌజ్ చేయడానికి Ctrl-E; మీరు స్టేట్‌మెంట్ టైప్ చేసి, ఎంటర్ నొక్కి, అది రన్ అవ్వడం చూసే ఇంటరాక్టివ్ షెల్ కోసం Ctrl-T, ఇక్కడ సెషన్ మునుపటి లైన్‌లను గుర్తుంచుకుంటుంది కాబట్టి మీరు ఒక్కో అడుగు వేస్తూ ఏదైనా నిర్మించవచ్చు; మరియు సేవ్ చేయడానికి Ctrl-S, లోడ్ చేయడానికి Ctrl-L, క్విట్ చేయడానికి Ctrl-Q.

Windows లో IDE ఇంకా అందుబాటులో లేదు; దానికి బదులుగా ఇంటరాక్టివ్ షెల్‌ను ఉపయోగించండి.

Speed, measured rather than claimed

కంపైలర్ వేరియబుల్ వాల్యూలను మెమరీకి బదులుగా ప్రాసెసర్ రిజిస్టర్లలో ఉంచుతుంది. ఒక రిప్రజెంటేటివ్ న్యూమరికల్ ప్రోగ్రామ్‌లో ఇది ఇటీవలి రౌండ్లలో సుమారు 1.2 రెట్లు కొలిచిన స్పీడ్-అప్‌ను ఇచ్చింది, మరియు టైట్ ఇంటిజర్ లూప్‌లో జనరేట్ చేయబడిన కోడ్ 13 ఇన్‌స్ట్రక్షన్స్ నుండి 5 కి తగ్గింది — కొలిచిన 4.9 రెట్లు. ఈ సెక్షన్‌లోని ప్రతి క్లెయిమ్ అంచనా వేయబడలేదు, ఒకే మెషీన్‌లో ముందు మరియు తర్వాత కొలవబడింది.

What the project is careful about

నాలుగు మెమరీ-కరప్షన్ బగ్‌లు కనుగొనబడి పరిష్కరించబడ్డాయి, ప్రతిదీ ఇప్పుడు శాశ్వత టెస్ట్ ద్వారా కవర్ చేయబడింది. కంపైలర్ 160 టెస్ట్‌లు మరియు పన్నెండు కోడ్-షేప్ గేట్‌ల ద్వారా చెక్ చేయబడుతుంది, ఇవి ఇచ్చిన కన్‌స్ట్రక్ట్ ఎంత కోడ్‌ను ఉత్పత్తి చేయడానికి అనుమతించబడుతుందో నిర్ధారిస్తాయి. ప్రాజెక్ట్ ఏదైనా వెరిఫై చేయలేన చోట — నిజమైన Windows మెషీన్‌లో Windows ఇంకా రన్ చేయబడలేదు — అది వేరేలా సూచించకుండా స్పష్టంగా చెబుతుంది.
