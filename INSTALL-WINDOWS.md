# Installing Sutram on Windows

The maintained installer route, artifact locations, privileges, legacy NSIS
warning and known build-wrapper discrepancy are in
[Installation routes](docs/INSTALLATION-ROUTES.md). That document is authoritative.

Use a verified native per-user package or a coherent portable directory. Do not
follow older Program Files, WSL/admin, machine-PATH or protection-bypass guidance.
A source-review supplement is not an installer or a complete portable checkout.

For compiling/running programs see [Windows usage](docs/WINDOWS-SETUP.md).
For manual GUI verification see
[R68 Windows GUI checklist](docs/R68-WINDOWS-GUI-CHECKLIST.md).
No installation or Windows acceptance result is claimed by this pointer page.
