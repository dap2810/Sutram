## One minimal consolidation strategy

Create **one small `docs/SPEC-STATUS.md` index**, with rows: `Implemented on main`, `Implemented on unmerged branch`, `Historical first-stage`, `Proposed, not accepted`, and `Future benchmark acceptance`. Keep original round documents immutable as dated evidence, link the above latest sources with source SHA/branch and exact syntax. **Avoid physically merging all round files into a huge replacement**; differing version/target scopes are the point. This is a suggestion for Sarvam's **prose scope**, not a request to edit `src/` or add a new test.

**Do NOT:** renumber `SUTRAMO2` as a sidecar header; add `cstr_ro` to already-shipped v2; declare all ELF relocations unsupported; call 7/7 future benchmark requirement achieved; present Windows v245 branch acceptance as release of the current main installer; rewrite dated R97/R100 results as if those tests had happened on v318; change any frozen language pack.
