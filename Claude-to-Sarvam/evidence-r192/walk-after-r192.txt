== Chapter 1, "What you need", as printed
   What you need: a Linux x86-64 system, or 64-bit Windows 10 or 11 (chapter 17 installs
   Sutram there; WSL is not needed). No other dependency — not even a C compiler. The compiler is a single
   self-contained binary. On Linux it is the file sutram_compiler at the top of the Sutram folder:
   run it as ./sutram_compiler, or copy it to a folder on your PATH under the name sutram,
   which is the name this book types.

== Chapter 2, the first program, as printed
   mukhya()
       likha("Namaste, Sutram!\n")
   -- the book says the student will see:
   $ sutram namaste.sm namaste.bin
   Siddh: 112 baait sankalit
   $ ./namaste.bin
   Namaste, Sutram!
   -- the student sees:
   $ sutram namaste.sm namaste.bin
     Siddh: 112 baait sankalit
   $ ./namaste.bin   typed ''           ->  'Namaste, Sutram!\n'

== Input section, block 1
     | mukhya() {
     |     vitti yoga = 0
     |     yavat (1) {
     |         vitti a = grahan()
     |         yadi (nivesha_anta()) { krama }
     |         yoga = yoga + a
     |     }
     |     likha("yoga: ", yoga, "\n")
     | }
   $ sutram p1.sm p1.bin
     Siddh: 487 baait sankalit
   $ ./p1.bin   typed 'hello\n'    ->  'yoga: 0\n'
   $ ./p1.bin   typed '42\n'       ->  'yoga: 42\n'
   $ ./p1.bin   typed '5\n-1\n3\n' ->  'yoga: 7\n'
   $ ./p1.bin   typed ''           ->  'yoga: 0\n'
