== m1: 200,000 calls, each making a mala of 31 numbers (256 bytes with its length word) inside a block: the sum, parimana() at the end, peak

    mandapa {
        mala b[31]
        b[0] = i
        nivartanam b[0]
    }
    nivartanam 0
}
mukhya() {
    vitti s = 0
    chakra i = 1 tak 200000 {
