# R34-11 — The FFI's version header, and the new checks

## `sutram-ffi-v1` and `sutram-ffi-v2`

**The change is in `r32_load_sidecar` (`src/r32_ffi.inc`), and nowhere else.**

- **The header's 13th byte is the version.** It must be `1` or `2`; the rest of the header is compared exactly,
  as before.
- **Under v1, an argument kind other than `i64`, or a result other than `i64`, is a malformed line,** with its line
  number. That is R32's rule, which R33 had relaxed without changing the header.
- **Under v2, the R33 kinds** (`f64`, `ptr`; a `void` result).
- **Nothing after parsing knows the version.** Code generation reads each declaration's kinds, so the same `i64`
  declarations give **the same object** under either header. That is tested.

**Why not keep one header:** a reader of a `.sffi` file should know what it may contain from its first line,
without knowing which compiler wrote or reads it. And a v1 file written for R32 must mean the same thing to every
later compiler. **Why not a feature list in the header:** two versions are one byte, and the next ABI (Windows,
`windows-x86_64-msabi`) is already the second field. That field is refused today, which is the right answer until
it exists.

**The fixtures moved with it.** `tests/r33/kinds.sffi` and `tools/fuzz_ffi.py` use `f64`, so they say `v2`.
`tests/r32/ffi.sffi` is `i64` only and stays `v1`. In `tests/r32/test_ffi.py`, the four R33-era "now accepted"
kinds are back to **refused under v1**, which is R32's original expectation, and `v0`, `v3` and the msabi ABI are
refused too.

## The new checks: `tests/r34/test_ffi_v2.py` (a gate, 14 checks)

| What | How |
|---|---|
| **the version** | the same `i64` file under v1 and v2: the same object; `f64` under v1: refused at line 2, no object |
| **a `dasham`, bit for bit** | `tests/r34/ffi_bits.c`: `b_from(bits) → double`, `b_of(double) → bits`, `b_twice(double, n)`. Eight special values go Sutram → C → Sutram → C, by expression and through a `dasham` variable, and come back unchanged: -0.0, +∞, −∞, a quiet NaN, a NaN with a payload, the smallest subnormal, the largest finite, 1.0 |
| **the arity edges** | a 0-argument declaration called with 1; a 6-argument one with 5; a call with 7 (more than Sutram's six): refused at compile time, exit 1, no object |
| **hostile sidecar bytes** | a NUL, an invalid UTF-8 sequence, a DEL, a tab: each refused at its line, no object |
| **the packs** | `E_FFI_KIND` in the Sanskrit and Gujarati packs |
