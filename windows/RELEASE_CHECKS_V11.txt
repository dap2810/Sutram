Sutram Windows v11 native installer - release checks
=====================================================

Release goal
------------
Build one native x64 Windows setup wizard that installs Sutram, optionally adds
Sutram to the machine PATH, creates Windows shortcuts, registers uninstall, and
requires no separate runtime/toolchain installation for the end user.

Validated in this release package
---------------------------------
- The Windows compiler host source and native host source are byte-for-byte
  identical to the v7 versions that built and passed the full smoke suite on the
  target Windows 11 machine. The native build script differs only in release/build
  plumbing, including the corrected standard sha256sum manifest parser.
- Windows compiler source is ASCII-stable and assembly quote-balanced.
- Windows PowerShell build/installer scripts pass structural compatibility scans
  for Windows PowerShell 5.1.
- Native installer C source passes an independent C11 syntax audit.
- Installer no longer depends on windres, IExpress, Inno Setup, or Visual Studio.
- Native setup build uses the same MinGW GCC toolchain that was detected on the
  target machine.
- Appended package footer layout is independently simulated and verified:
  offsets, sizes, contiguity, and SHA-256 hashes all agree with installer.c.
- Setup --self-test verifies all appended package parts before release/install.
- Payload has its own per-file SHA-256 manifest and rejects unmanifested files.
- Install folder validation rejects unsafe/non-local/overlong shell-sensitive
  paths before filesystem or PATH integration changes are made.
- Existing non-Sutram non-empty folders are rejected.
- PATH ownership is tracked. A manually existing PATH entry is not claimed and
  therefore is not removed by uninstall.
- Desktop shortcut ownership is tracked; a pre-existing user shortcut is kept.
- Uninstall deletes only manifest-owned payload files and installer-owned Windows
  integration. It does not recursively delete unknown/user-created folders.
- Sutram install markers are content-validated before upgrade/uninstall.
- Final build script verifies PE32+ x64 output, runs setup --self-test, verifies
  the release-copy SHA-256, and writes Sutram-Setup.exe in the project root.

Target-machine build checks performed automatically
----------------------------------------------------
BUILD-WINDOWS-SETUP.cmd runs all of the following on Windows before it reports
BUILD PASSED:
1. Source SHA-256 integrity verification using the same standard manifest parser in preflight and native-build stages.
2. Windows 11 / PowerShell / toolchain preflight.
3. Real MinGW Win32 compiler/linker probe (no windres).
4. Native Sutram compiler build and the existing comprehensive smoke suite.
5. Native x64 setup-wizard compilation.
6. Appended payload creation plus SHA-256 footer generation.
7. Setup --self-test of every appended package part.
8. Final PE32+ x64 and release-copy hash verification.

Known compiler boundary
-----------------------
The Sutram compiler host itself is native Windows x64. Programs generated by
Sutram still use the transitional ELF backend. Native PE64 generated-program
output remains a separate compiler-backend development stage.
