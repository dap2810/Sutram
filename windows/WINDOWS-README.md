# Sutram for Windows

See [the canonical installation routes](../docs/INSTALLATION-ROUTES.md) for the
supported native per-user installer, build paths, legacy NSIS distinction and
unresolved main-branch wrapper discrepancy. Do not use historical WSL/admin or
system-PATH instructions as a fallback.

The source GUI builder is `gui/build-gui.ps1`. Window behavior must be checked
on a real Windows desktop using
[the manual GUI checklist](../docs/R68-WINDOWS-GUI-CHECKLIST.md).
This page does not certify a GUI, compiler, installer, or uninstaller run.
