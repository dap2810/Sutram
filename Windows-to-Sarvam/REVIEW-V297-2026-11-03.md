## Findings to reconcile

- Windows memory accounting reports zero; the allocation budget is not enforced.
- `kosh` alias mutations differ from the expected shared behavior.
- Examples 322/323 produce corrupt character output and terminate abnormally;
  native runs recorded access violation 0xC0000005.
- The IDE refuses a 70,422-byte example. Save/unsaved-text protections passed.
- Eight nested native-script examples fail under Auto but match expectations
  when the appropriate language is explicitly selected. No frozen pack was changed.
- A nested boundary example fails to compile; other differences and caveats are
  detailed in the IDE report. Do not equate output matches with verified exit codes.
- Existing installation is v297, but the legacy user PATH entry precedes it:
  outside the repository, bare `sutram` resolves to legacy `Sutram 1.4.0`.
  Running CMD in the repository root masks this by selecting its v297 executable.
- Installer/uninstaller acceptance remains incomplete. The installed IDE was
  exercised and photographed; English UI labels remain. The supplied division-by-zero
  example prints Latin-transliterated Sanskrit, while the separate Devanagari
  example visibly renders correctly.

Please distinguish the old native harness's missing Hindi flag from a compiler
