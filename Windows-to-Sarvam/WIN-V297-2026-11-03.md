## Build provenance

A clean `git archive` export is retained at `build/windows-v297/source`.
The compiler, GUI, linker and installer were rebuilt with NASM and GNU ld.
The existing setup script does not rebuild the linker, so it was built separately
from `linker/sutram_link.asm` with `-f win64 -DWINDOWS=1`, then linked with
`-mi386pep --subsystem console --entry=_start --no-insert-timestamp`.

The committed source-integrity manifest mismatched 311 files even in the clean
export. The manifest was regenerated only in that isolated export. The working
checkout also uses CRLF conversion; this alone does not explain the stale manifest.
Both linkers on this machine initially failed to locate GUI import libraries.
Only the isolated build helper was adapted to prepend
`-LC:/Program Files/mingw64/x86_64-w64-mingw32/lib` to ld arguments, and the manifest
was regenerated again. Process-local PATH selected that MinGW bin directory.
These local build adaptations are not proposed or merged source changes.
All eleven packs are packaged; non-Sanskrit pack sources are unchanged.
