17.6 Understanding PATH

PATH is the suchi of folders Windows searches when you type a command. If Sutram's folder is on PATH, you can type sutram from anywhere; otherwise you must type the full path or be in the folder.

To check: open a new terminal and run sutram --version. If it prints the version, PATH is sangrah. If not, either re-run the installer with the PATH option, or run sutram.exe from the folder that contains it.
